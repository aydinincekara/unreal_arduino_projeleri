Proje 8: Gerçek Sürüş Hissi

Analog Joystick ile Chaos Vehicles Araç Fiziği Kontrolü

🎯 Senaryo: Kendi Yarış Simülatörümüz

Unreal Engine 5 ile birlikte araç fizikleri tamamen yenilendi ve Chaos Vehicles eklentisi standart hale geldi. Bir aracı kodlarken, doğrudan arabanın kendisine değil, arabanın içindeki motor, şanzıman ve tekerlek fiziklerini hesaplayan Vehicle Movement Component (Araç Hareket Bileşeni) adlı sisteme komut göndeririz.

Bu projede, standart bir Analog Joystick (PlayStation veya Xbox kolundaki çubukların aynısı) modülünü kullanarak, yatay ekseni direksiyon (Steering), dikey ekseni ise gaz/fren (Throttle/Brake) olarak kullanacağız.




🤖 1. Fiziksel Katman: Arduino Kodu

Analog Joystick'in iki ekseni vardır: VRx ve VRy. Bunları A0 ve A1 pinlerine bağlayacağız. Veriyi saf 0-1023 olarak göndermek yerine, Unreal'ın araç fiziğinin kolay anlayacağı şekilde merkez noktayı 0 yapıp, -100 ile +100 arasında bir değer üreteceğiz.

// ARDUINO KODU: Joystick Verisini Formatla ve Gönder
void setup() {
  Serial.begin(9600);
}

void loop() {
  // Joystick serbestken 512 civarıdır. map() ile bunu 0'a ortalıyoruz.
  // Sola çekince -100, sağa çekince +100 olacak.
  int direksiyon = map(analogRead(A0), 0, 1023, -100, 100);
  
  // Yukarı itince gaz (+100), aşağı çekince fren/geri (-100)
  int gazFren = map(analogRead(A1), 0, 1023, -100, 100);

  // Ölü Bölge (Deadzone) Ayarı: Hassas sensör titremelerini engeller
  if(direksiyon > -10 && direksiyon < 10) direksiyon = 0;
  if(gazFren > -10 && gazFren < 10) gazFren = 0;

  // ÇOKLU VERİ PAKETLEME: "Direksiyon,GazFren\n" formatı
  Serial.print(direksiyon);
  Serial.print(",");
  Serial.println(gazFren); // Alt satıra in!
  
  delay(20); // 50Hz akış
}
💡 Deadzone (Ölü Bölge) Neden Önemli?: Analog çubuklar parmağınızı çektiğinizde tam sıfıra dönmeyebilir (-3 veya +2 kalabilir). Bu da oyundaki arabanızın kendi kendine hafifçe sağa kaymasına sebep olur. Kodda yazdığımız if şartı bu titremeyi yok eder.

🟦 2. Blueprint (Unreal Engine) Kodlaması

Öncelikle projenizde Edit -> Plugins sekmesinden Chaos Vehicles Plugin'in aktif olduğundan emin olun. Epic Games'in hazır sunduğu "Vehicle Template" (Spor Araba) üzerinden gitmek işleri çok hızlandırır.




Adım Adım Bağlantılar:

  1. Arabayı Dinlemeye Almak: Spor arabanızın Blueprint'ine girin. Event Tick üzerinden Read Line ile gelen "Direksiyon,GazFren" verisini okuyun ve Parse Into Array (Virgül ile ayırıcı) düğümüyle parçalayın.
  2. Direksiyonu Bağlamak (X Ekseni - Index 0):
    • Get (0) ile ilk veriyi alın ve To Float ile ondalıklı sayıya çevirin.
    • Chaos fizik motoru direksiyon açısını -1.0 (Tam Sol) ile 1.0 (Tam Sağ) arasında kabul eder.
    • Gelen veriyi (-100/100) dönüştürmek için Map Range Clamped kullanın (Out: -1.0 / 1.0).
    • Sol menüden (Components) Vehicle Movement Component'i sahneye sürükleyin. Ondan bir kablo çekin ve Set Steering Input düğümünü bulun. Oranladığınız sayıyı buraya bağlayın.
  3. Gaz ve Freni Bağlamak (Y Ekseni - Index 1):
    • Get (1) ile ikinci veriyi alın.
    • Yukarı ittiğinizde (Örn: 0 ile 100 arası) Vehicle Movement Component'den Set Throttle Input düğümüne 0.0 - 1.0 arası gönderin.
    • Aşağı çektiğinizde (Örn: -100 ile 0 arası) sayının eksisini kaldırıp (Absolute Value) yine 0.0 - 1.0 arasında Set Brake Input düğümüne gönderin.
⚠️ Önemli: Normal objeleri hareket ettirirken Add Actor Local Offset kullanırız. Ancak araçlarda motor devri, tekerlek sürtünmesi ve süspansiyon hesaplandığı için mutlaka Chaos Vehicle Movement Component içindeki Input (Girdi) fonksiyonlarını kullanmalısınız!

🚀 Atölye Tatbikatı: Handbrake (El Freni) Ekleme

Laboratuvar testini yaptıktan sonra gençlere yeni bir görev verin: Analog Joystick modülünün üzerinde aslında tıklanabilen bir SW (Switch/Buton) bulunur.

Proje 1'de öğrendikleri buton okuma mantığını kullanarak, Joystick'in üzerine basıldığında Arduino'dan 3. bir veri ("Direksiyon,Gaz,Buton") göndermelerini sağlayın. Bu buton verisi 1 olduğunda Unreal Engine'deki Set Handbrake Input (El Freni) düğümünü aktifleştirerek araca fiziksel drift yaptırmalarını isteyin!
