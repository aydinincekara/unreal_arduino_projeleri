Proje 25: Akıllı Laboratuvar

Çoklu Düğüm (Multi-Node) IoT Ağı ve Dijital İkiz (Digital Twin) Yönetimi

🎯 Senaryo: Veri Merkezini Kurmak (Dijital İkiz)

Endüstriyel yazılımların ve modern oyunların ortak noktası "Büyük Veri" (Big Data) yönetimidir. Şu ana kadar Unreal Engine'e tek bir kaynaktan veri gönderdik. Peki ya laboratuvarımızdaki 5 farklı masada 5 farklı ESP32 aynı anda çalışıp ana sunucuya (Unreal Engine) veri gönderirse ne olur?

Bu projede, her masadaki ESP32 kendisine özel bir kimlik (ID) ile ağa veri fırlatacak. Unreal Engine bu verileri havada yakalayacak, hangi masadan ve hangi sensörden geldiğini ayrıştıracak ve laboratuvarın 3D kopyasındaki (Dijital İkiz) ilgili göstergeleri güncelleyecektir.




🤖 1. Fiziksel Katman: Düğüm (Node) Kimliklendirmesi

Bu kod, laboratuvardaki farklı masalara dağıtacağımız ESP32'lerin şablon kodudur. Ağdaki karışıklığı önlemek için veriyi "MASA_NO,SENSOR_TIPI,DEGER" formatında paketleyip göndereceğiz.

// ESP32 KODU: Düğüm (Node) Veri Gönderimi
#include <WiFi.h>
#include <WiFiUdp.h>

// Ağ Ayarları
const char* ssid = "Laboratuvar_WiFi";
const char* password = "Sifre1234";
const char* unrealIP = "192.168.1.100"; // Ana Sunucu Bilgisayarın IP'si
const int unrealPort = 8888; 

WiFiUDP udp;

// --- BU KISMI HER MASADA DEĞİŞTİRİN ---
String MASA_ID = "MASA_1"; 
// --------------------------------------

const int isiSensorPin = A0; // Örnek bir analog sensör

void setup() {
  Serial.begin(115200);
  WiFi.begin(ssid, password);
  while (WiFi.status() != WL_CONNECTED) { delay(500); }
}

void loop() {
  // Sensörden değeri oku
  int deger = analogRead(isiSensorPin);

  // Veri Paketini Oluştur (Örn: "MASA_1,ISI,450")
  String veriPaketi = MASA_ID + ",ISI," + String(deger);

  // UDP ile fırlat
  udp.beginPacket(unrealIP, unrealPort);
  udp.print(veriPaketi);
  udp.endPacket();

  // Ağı yormamak için 1 saniye bekle (IoT ağlarında verimlilik esastır)
  delay(1000); 
}
💡 Multi-Node (Çoklu Düğüm) Mantığı: UDP protokolü aynı anda birden fazla cihazın aynı porta veri fırlatmasına izin verir. Ana bilgisayar IP adresiniz değişmediği sürece atölyeye 50 adet ESP32 koysanız bile hepsi Unreal'a sorunsuz ulaşır.

🟦 2. Blueprint (Unreal Engine) Merkezi Yönetim Sistemi

Unreal Engine tarafında artık sıradan bir karakter kontrolcüsü değil, devasa bir Veri Dağıtım Merkezi (Dispatcher) kuruyoruz.




Adım Adım Bağlantılar (Gelişmiş Ayrıştırma):

  1. Gelen Sinyali Yakalamak: Event On UDP Message Received ile gelen Byte dizisini Bytes to String ile metne dönüştürün.
  2. Parçalama (Parsing): Metni Parse Into Array düğümüne sokun. Ayırıcı (Delimiter) olarak virgül , kullanın. Bu bize 3 elemanlı bir liste (Array) verecektir.
  3. Ana Dağıtıcı (Hangi Masa?):
    • Get (0) düğümünü çağırıp ilk veriyi alın.
    • Bunu bir Switch on String düğümüne bağlayın.
    • Pin isimlerini laboratuvardaki masalara göre ayarlayın: MASA_1, MASA_2, MASA_3.
  4. Alt Dağıtıcı (Hangi Sensör?):
    • Örneğin MASA_1 pininden çıkan kabloyu ikinci bir Switch on String düğümüne bağlayın.
    • Bu ikinci Switch'in String girişine Get (1) (Yani Sensör Tipi) düğümünü bağlayın.
    • Pinleri sensör türlerine göre ayarlayın: ISI, BUTON, RFID.
  5. Veriyi İşleme:
    • Eğer Masa 1'den ISI geldiyse, Get (2) düğümünü (Sensör değeri) alıp To Float yapın.
    • Bu değeri kullanarak sahnedeki "Masa 1 Hologramı"nın rengini (Set Vector Parameter Value) kırmızı veya mavi yaparak sıcaklığı görselleştirin!
⚠️ Cast İşlemleri: Gerçek bir projede yüzlerce kablo çekmek yerine, MASA_1 sinyali geldiğinde sahnede bulunan BP_Masa1 aktörüne Cast To yaparak doğrudan o aktörün içindeki bir fonksiyonu (Örn: SicaklikGuncelle) tetiklemek çok daha profesyonel bir (OOP - Nesne Yönelimli Programlama) yaklaşımıdır.

🚀 Atölye Tatbikatı: Kumanda Merkezi (Command Center)

ARGE ekibini 3 veya 4 küçük gruba ayırın. Her gruba bir ESP32 ve farklı türde bir sensör (Buton, LDR, Isı vb.) verin. Kendi masa ID'lerini ("Kırmızı_Takim", "Mavi_Takim" gibi) belirlesinler.

Unreal Engine projesini tam ekrana alın (F11). Sahnede her takım için bir 3D platform olsun. Takımlar kendi masalarındaki sensörlerle oynadıkça, ana ekrandaki platformlarının renk değiştirmesini, yükselmesini veya ateş püskürtmesini canlı olarak izlesinler. Bu, endüstriyel SCADA (Veri Tabanlı Kontrol ve Gözetleme) sistemlerinin oyunlaştırılarak öğretilmesinin zirvesidir!
