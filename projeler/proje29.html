Proje 29: ESP-NOW

Modemsiz (Router-less) Çoklu Oyuncu Fiziksel Kumanda Mimarisi

🎯 Senaryo: Odanızdaki E-Spor Turnuvası

Eğer laboratuvardaki internet bağlantısı yavaşsa veya modem kısıtlamaları (Port sınırları) varsa, Wi-Fi üzerinden UDP kullanmak gecikmelere (Ping) yol açabilir. Dövüş oyunları (Mortal Kombat, Tekken) veya yarış oyunlarında (Mario Kart) milisaniyeler bile çok önemlidir.

ESP-NOW ile her oyuncunun elindeki kumanda (ESP32 Verici), oyunu oynatan bilgisayara takılı olan tek bir ESP32'ye (Alıcı USB Dongle) cihazların MAC Adresleri üzerinden doğrudan bağlanır. Tıpkı PlayStation veya Xbox'ın kablosuz kontrolcülerinde olduğu gibi kesintisiz, internetsiz ve yüksek hızlı bir çoklu oyuncu (Local Multiplayer) deneyimi yaratacağız.




🤖 1. Fiziksel Katman: Verici ve Alıcı Mimarisi

Bu projede iki farklı koda ihtiyacımız var. Biri oyuncuların elindeki kumandalara, diğeri bilgisayardaki alıcıya yüklenecektir. ESP-NOW'da veri gönderimi struct (Veri Yapısı) paketleriyle yapılır.

// 1. VERİCİ (KUMANDA) KODU - Oyuncu 1'in elindeki ESP32
#include <esp_now.h>
#include <WiFi.h>

// Bilgisayara takılı olan ALICI ESP32'nin MAC Adresini buraya yazın
uint8_t aliciMAC[] = {0x24, 0x6F, 0x28, 0xAE, 0x77, 0x90};

// Veri Paketimizin Yapısı
typedef struct struct_message {
  int playerID;
  int buttonState;
} struct_message;

struct_message gidenVeri;
esp_now_peer_info_t peerInfo;
const int atesButon = 4;

void setup() {
  Serial.begin(115200);
  pinMode(atesButon, INPUT_PULLUP);
  
  WiFi.mode(WIFI_STA); // Wi-Fi İstasyon Modu
  
  if (esp_now_init() != ESP_OK) {
    Serial.println("ESP-NOW Baslatilamadi!");
    return;
  }

  // Alıcıyı kaydet (Pairing)
  memcpy(peerInfo.peer_addr, aliciMAC, 6);
  peerInfo.channel = 0;  
  peerInfo.encrypt = false;
  esp_now_add_peer(&peerInfo);
}

void loop() {
  gidenVeri.playerID = 1; // 2. Kumanda için burayı 2 yapın
  gidenVeri.buttonState = !digitalRead(atesButon); // Basılıysa 1, değilse 0
  
  // Veriyi Gönder
  esp_now_send(aliciMAC, (uint8_t *) &gidenVeri, sizeof(gidenVeri));
  delay(20); // 50 Hz Hız (Çok hızlı tepki süresi)
}
// 2. ALICI (DONGLE) KODU - PC'ye USB ile bağlı olan ESP32
#include <esp_now.h>
#include <WiFi.h>

typedef struct struct_message {
  int playerID;
  int buttonState;
} struct_message;

struct_message gelenVeri;

// Veri geldiğinde tetiklenecek fonksiyon (Callback)
void OnDataRecv(const uint8_t * mac, const uint8_t *incomingData, int len) {
  memcpy(&gelenVeri, incomingData, sizeof(gelenVeri));
  
  // Gelen veriyi Serial Port üzerinden Unreal Engine'e yazdır
  // Format: PlayerID,ButtonState (Örn: 1,1 veya 2,0)
  Serial.print(gelenVeri.playerID);
  Serial.print(",");
  Serial.println(gelenVeri.buttonState);
}

void setup() {
  Serial.begin(9600); // Unreal Engine SerialCOM hızı
  WiFi.mode(WIFI_STA);
  esp_now_init();
  // Dinleyiciyi başlat
  esp_now_register_recv_cb(OnDataRecv); 
}

void loop() {
  // Alıcı ESP32'nin loop döngüsü boş kalır, veri geldikçe Callback çalışır.
}

🟦 2. Blueprint (Unreal Engine) Karakter Ayrıştırması

Unreal Engine tarafında SerialCOM eklentisi (Seviye 1'deki altyapımız) USB'ye bağlı olan Alıcı ESP32'yi dinleyecektir. Gelen verinin başındaki PlayerID numarasına göre doğru karakteri hareket ettirmemiz gerekir.




Adım Adım Bağlantılar:

  1. Sinyali Dinlemek: Event Tick -> Read Line ile metni okuyup Parse Into Array (Ayırıcı: Virgül) ile bölün.
  2. Hangi Oyuncu?: Get (0) düğümünden çıkan sonucu (Oyuncu kimliği) bir Switch on String düğümüne bağlayın. Pinleri 1 ve 2 olarak oluşturun.
  3. Komutu Aktarmak (Player 1): Switch'in 1 çıkışından kablo çekin. Sahnedeki Player 1 Pawn referansınıza (veya Cast işlemiyle) ulaşıp, Get (1) pininden gelen "Buton" verisini (Eşittir == 1 ise True) Player 1'in zıplama veya ateş etme fonksiyonuna bağlayın.
  4. Komutu Aktarmak (Player 2): Switch'in 2 çıkışından kablo çekin ve aynı işlemi sahnede bulunan Player 2 Pawn karakteri için uygulayın.
⚠️ Çoklu Oyuncu Çakışması (Ghosting): Aynı anda yüzlerce milisaniyelik veri geldiği için Blueprint'te DoOnce veya Cooldown (Gecikme) sistemlerini karakterlerin kendi içlerine (Character Blueprint) yerleştirmeniz, oyunun akıcılığını artıracaktır.
