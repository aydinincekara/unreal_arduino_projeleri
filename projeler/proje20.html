Proje 20: Seviye 3 Finali

Tüm Sistemlerin Birleşimi: Fiziksel Kokpit Tasarımı ve Simülatör

🎯 Senaryo: Kendi Uzay Gemimizi Uçurmak

Seviye 3 boyunca tekil sensörlerin ve modüllerin Unreal Engine'in farklı özelliklerini nasıl kontrol ettiğini öğrendik. Şimdi tüm bu modülleri devasa bir kontrol paneline (Kokpit) entegre ediyoruz.

  • Joystick: Gemiyi sağa/sola ve yukarı/aşağı yönlendirecek.
  • Arcade Buton: Geminin lazer silahlarını ateşleyecek.
  • Rotary Encoder: Geminin kalkan (Shield) türünü (Ateş, Buz, Enerji) seçecek.
  • OLED Ekran: Kalan mermimizi ve seçili kalkan türünü canlı olarak gösterecek.



🤖 1. Fiziksel Katman: Dev Veri Paketi (Data Payload)

Arduino'nun neredeyse tüm pinlerini kullanacağız. Bu kadar çok sensör varken her birini ayrı satırlarda göndermek Unreal Engine tarafında karmaşaya yol açar. Bu yüzden tüm verileri virgüllerle ayırarak tek bir "Veri Paketi" (Data Payload) halinde göndereceğiz: JoyX,JoyY,AtesButonu,KalkanTuru\n

// ARDUINO KODU: Kokpit Veri Birleştirici
#include <Wire.h>
#include <Adafruit_GFX.h>
#include <Adafruit_SSD1306.h>

Adafruit_SSD1306 display(128, 64, &Wire, -1);

// Pin Tanımlamaları
const int joyXPin = A0;
const int joyYPin = A1;
const int atesButonPin = 2;
const int encClk = 3;
const int encDt = 4;

// Değişkenler
int kalkanTuru = 0;
int sonClk;

void setup() {
  Serial.begin(9600);
  pinMode(atesButonPin, INPUT_PULLUP);
  pinMode(encClk, INPUT);
  pinMode(encDt, INPUT);
  
  display.begin(SSD1306_SWITCHCAPVCC, 0x3C);
  sonClk = digitalRead(encClk);
}

void loop() {
  // 1. Joystick Verilerini Oku ve Haritala (-100 ile 100 arası)
  int jX = map(analogRead(joyXPin), 0, 1023, -100, 100);
  int jY = map(analogRead(joyYPin), 0, 1023, -100, 100);
  if(abs(jX) < 10) jX = 0; // Deadzone
  if(abs(jY) < 10) jY = 0;

  // 2. Ateş Butonunu Oku (Basılıysa 1, Değilse 0)
  int ates = !digitalRead(atesButonPin);

  // 3. Enkoderi Oku (Kalkan Türünü Değiştir)
  int anlikClk = digitalRead(encClk);
  if (anlikClk != sonClk && anlikClk == 1) {
    if (digitalRead(encDt) != anlikClk) kalkanTuru++; else kalkanTuru--;
    // Dairesel limit (0, 1, 2 arasında dönsün)
    if(kalkanTuru > 2) kalkanTuru = 0;
    if(kalkanTuru < 0) kalkanTuru = 2;
  }
  sonClk = anlikClk;

  // 4. BÜYÜK VERİ PAKETİNİ OLUŞTUR VE GÖNDER
  // Format: JoyX,JoyY,Ates,KalkanTuru
  Serial.print(jX); Serial.print(",");
  Serial.print(jY); Serial.print(",");
  Serial.print(ates); Serial.print(",");
  Serial.println(kalkanTuru);

  // 5. Unreal'dan Gelen Veriyi OLED'e Yaz (Mermi Durumu)
  if(Serial.available() > 0) {
    String mermi = Serial.readStringUntil('\n');
    display.clearDisplay();
    display.setTextSize(2); display.setTextColor(WHITE);
    display.setCursor(0, 10); display.println("KALKAN: " + String(kalkanTuru));
    display.setCursor(0, 40); display.println(mermi);
    display.display();
  }
  
  delay(20); // Stabilizasyon
}

🟦 2. Blueprint (Unreal Engine) Parsing (Ayrıştırma) Mimarisi

Unreal Engine tarafında karakterimizin Blueprint'inde tek bir Parse Into Array düğümü kullanarak gelen bu uzun cümleyi 4 ayrı komuta böleceğiz.




Adım Adım Ayrıştırma:

  1. Event Tick -> Read Line ile okunan metni alıp Parse Into Array (Ayırıcı: Virgül) düğümüne sokun.
  2. Index 0 ve 1 (Joystick): Get(0) ve Get(1) düğümlerinden çıkan değerleri Float'a çevirin. Bunları Map Range Clamped ile -1.0 ve 1.0 arasına oranlayıp karakterinizin Add Movement Input veya Add Controller Pitch/Yaw Input düğümlerine bağlayarak gemiyi uçurun.
  3. Index 2 (Ateş Butonu): Get(2) değerini Integer'a çevirin. Equal (== 1) düğümüyle kontrol edin. Eğer True ise ve Cooldown süresi dolmuşsa Spawn Actor from Class ile geminizden lazer ateşleyin.
  4. Index 3 (Kalkan): Get(3) değerini Integer'a çevirin. Bir Switch on Int düğümüne bağlayarak 0, 1, 2 çıkışlarına geminin etrafındaki kalkanın Materyalini (Renklerini) değiştiren düğümleri bağlayın.
