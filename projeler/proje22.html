ESP32 ve MPU6050 İle Kablosuz VR Kontrolcüsü Geliştirme

🎯 Senaryo: Odanız Artık Bir Savaş Alanı

Meta Quest (Oculus) veya HTC Vive gibi VR sistemlerinin kontrolcüleri, içlerindeki yüksek hassasiyetli jiroskop verilerini bilgisayara kablosuz olarak gönderirler. Biz de kendi R&D (ARGE) atölyemizde tamamen kendi kodladığımız ve 3D yazıcıdan çıkardığımız bir kılıç kabzasıyla aynı sistemi inşa ediyoruz.

ESP32, üzerine bağlanan MPU6050 sensöründen X ve Y eksenindeki eğim (Pitch ve Roll) verilerini okuyacak ve bunları X,Y formatında, saniyede 50 defa UDP paketi olarak Unreal Engine'e fırlatacak.




🤖 1. Fiziksel Katman: Wi-Fi İvmeölçer Kodlaması

MPU6050 modülü I2C üzerinden haberleşir. ESP32 üzerinde I2C pinleri genellikle SDA -> GPIO 21 ve SCL -> GPIO 22'dir. Modülün VCC pinini ESP32'nin 3.3V pinine bağlamayı unutmayın (5V kullanmak ESP32'ye zarar verebilir).

// ESP32 KODU: MPU6050 Verilerini UDP ile Kablosuz Gönderme
#include <WiFi.h>
#include <WiFiUdp.h>
#include <Wire.h>
#include <Adafruit_MPU6050.h>
#include <Adafruit_Sensor.h>

// Ağ Ayarları
const char* ssid = "Laboratuvar_WiFi";
const char* password = "Sifre1234";
const char* unrealIP = "192.168.1.100"; 
const int unrealPort = 8888; 

WiFiUDP udp;
Adafruit_MPU6050 mpu;

void setup() {
  Serial.begin(115200);

  // MPU6050 Başlatma
  if (!mpu.begin()) {
    Serial.println("MPU6050 Bulunamadi!");
    while (1) delay(10);
  }
  
  // Hassasiyet Ayarları (Daha pürüzsüz hareket için)
  mpu.setAccelerometerRange(MPU6050_RANGE_4_G);
  mpu.setFilterBandwidth(MPU6050_BAND_21_HZ);

  // Wi-Fi Bağlantısı
  WiFi.begin(ssid, password);
  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
  }
}

void loop() {
  sensors_event_t a, g, temp;
  mpu.getEvent(&a, &g, &temp);

  // İvme değerlerini al (m/s^2)
  float x = a.acceleration.x;
  float y = a.acceleration.y;

  // UDP Paketini Gönder (Format: X,Y)
  udp.beginPacket(unrealIP, unrealPort);
  udp.print(x);
  udp.print(",");
  udp.print(y);
  udp.endPacket();

  // Veri yığılmasını (Packet Loss) önlemek için 20ms bekle (50 FPS)
  delay(20); 
}
💡 Titreşimleri Azaltmak: setFilterBandwidth ayarı donanımsal bir filtredir. Titreyen bir elin hareketlerini yumuşatarak oyun motoruna çok daha pürüzsüz veriler akmasını sağlar.

🟦 2. Blueprint (Unreal Engine) Kodlaması

Karakterinizin eline (Skeletal Mesh'teki sağ el soketine) bir Kılıç veya Asab modeli ekleyin. UDP'den saniyede 50 kez kablosuz olarak gelen "5.2,-3.4" tarzındaki metni parçalayıp bu kılıcın rotasyonuna bağlayacağız.




Adım Adım Bağlantılar:

  1. Kablosuz Veriyi Yakalamak: Proje 21'de kurduğumuz Event On UDP Message Received düğümünü kullanın. Gelen Byte verisini Bytes to String ile metne dönüştürün.
  2. Paketi Parçalamak: Gelen String verisini Parse Into Array düğümüne sokun (Ayırıcı/Delimiter kutusuna , yazın).
  3. Verileri Ayıklamak ve Oranlamak:
    • Get(0) (X Ekseni) düğümünü alıp To Float yapın. Arduino'dan gelen -10 ile +10 arası veriyi, Map Range Clamped ile kılıcın Roll (veya Pitch) ekseni için -90 ile +90 derece arasına oranlayın.
    • Get(1) (Y Ekseni) düğümünü alıp aynı şekilde Float'a çevirin ve diğer eksen için -90/+90 arasına oranlayın.
  4. Kılıcı Döndürmek: Çıkan oranlanmış açıları Make Rotator düğümünde uygun pinlere (Pitch ve Roll) takın. Son olarak kılıç (veya asab) referansınızı sahneye çekip Set Relative Rotation düğümüne bağlayın ve Make Rotator'dan çıkan sonucu buraya verin.
⚠️ Güvenlik Kilidi (Out of Bounds Hata Koruması): UDP paketleri havadan (Wi-Fi üzerinden) geldiği için bazen paket kayıpları olabilir ve eksik bir veri ("5.2," şeklinde) gelebilir. Parse Into Array düğümünden sonra mutlaka bir Length düğümü çekip, dizinin uzunluğunun tam olarak 2'ye eşit (==) olup olmadığını bir Branch ile kontrol edin. Yoksa oyun çöker!
