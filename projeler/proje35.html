Proje 35: Audio-Reactive Sistemler

Ses Sensörü ve Niagara Partikül Motoru ile Canlı Görsel Şov

🎯 Senaryo: Müziğin Formu

Oyun motorları artık devasa konser sahnelerinin arkasındaki dev LED ekranları (Volume) besleyen ana beyin konumunda. Müzik ritmine göre büyüyüp küçülen, renk değiştiren veya patlayan objeler, sahnede muazzam bir dinamizm yaratır.

Bu projede, bir **KY-038** veya **MAX4466** analog ses (mikrofon) sensörünü ESP32'ye bağlayacağız. Odanın içindeki müziğin bas vuruşlarını (Amplitude / Genlik) anlık olarak sayısallaştırıp Unreal Engine'e fırlatacağız. Unreal Engine'deki Niagara parçacık sisteminde özel bir değişken (User Parameter) oluşturarak ortamdaki müzik yüksekliğine göre bir alevin veya ses dalgası küresinin boyutunu değiştireceğiz.




🤖 1. Fiziksel Katman: Gürültü Filtreleme (Peak Detection)

Analog ses sensörlerinin A0 (Analog Out) bacağı, mikrofona gelen sesin frekans dalgalarını yansıtır. Ancak bize ham dalga değil, "Ses Şiddeti (Envelope)" lazımdır. Bunu bulmak için kısa bir zaman dilimindeki en yüksek ve en düşük dalga değerlerinin farkını (Peak-to-Peak) ölçeceğiz.

// ESP32 KODU: Ses Şiddeti (Amplitude) Ölçümü ve UDP Gönderimi
#include <WiFi.h>
#include <WiFiUdp.h>

const char* ssid = "Laboratuvar_WiFi";
const char* password = "Sifre1234";
const char* unrealIP = "192.168.1.100";
const int unrealPort = 8888;

WiFiUDP udp;
const int micPin = 34; // ESP32 Analog Girişi

void setup() {
  Serial.begin(115200);
  WiFi.begin(ssid, password);
  while (WiFi.status() != WL_CONNECTED) { delay(500); }
}

void loop() {
  unsigned long startMillis = millis();
  int signalMax = 0;
  int signalMin = 4095; // ESP32'nin maksimum ADC çözünürlüğü

  // 50 Milisaniye boyunca sesi dinle (Sampling Window)
  while (millis() - startMillis < 50) {
    int micVerisi = analogRead(micPin);
    if (micVerisi < 4095) {  // Parazit okumaları atla
      if (micVerisi > signalMax) { signalMax = micVerisi; }
      if (micVerisi < signalMin) { signalMin = micVerisi; }
    }
  }

  // Sesin tepe (Peak) şiddetini hesapla
  int peakToPeak = signalMax - signalMin;
  
  // UDP ile gönder (Örn: "BEAT,1500")
  String veriPaketi = "BEAT," + String(peakToPeak);
  
  udp.beginPacket(unrealIP, unrealPort);
  udp.print(veriPaketi);
  udp.endPacket();
}
💡 Ses Kartı Yerine Mikrofon: Normalde VJ programları sesi doğrudan bilgisayarın ses kartından (Loopback) alır. Ancak biz ortam sesini (seyircilerin alkışı, fiziksel davul vb.) yakalamak istediğimiz için dışarıdan donanımsal bir mikrofon kullanmak sanal prodüksiyonda eşsiz bir etkileşim sunar.

🟦 2. Unreal Engine Niagara Entegrasyonu

Unreal Engine 5'te Niagara parçacık sistemi muazzamdır. Niagara'nın kendi içindeki değişkenleri dışarıdan, yani Event Graph'tan anlık olarak kontrol edebiliriz.




Adım Adım Bağlantılar:

  1. Niagara Sisteminde Değişken Tanımlama:
    • İçerik çekmecesinden yeni bir Niagara System oluşturun (Örn: Ateş veya Küre).
    • Sistemi açın, sol taraftaki Parameters paneline gidin, '+' ikonuna tıklayıp yeni bir User Exposed -> Float değişkeni oluşturun (Adı: MuzikSiddeti olsun).
    • Partikülün "Spawn Rate" (Doğma Hızı) veya "Scale Sprite Size" (Boyut) bölümüne gidin. Sabit bir sayı girmek yerine az önce oluşturduğunuz User.MuzikSiddeti değişkenini sürükleyip o kutucuğa bağlayın. Artık partikül dışarıdan yönetilebilir oldu!
  2. Blueprint İle Veriyi Yollamak:
    • Sahnede bulunan Niagara Actor'ünün referansını Level Blueprint'e sürükleyin.
    • Ondan bir kablo çıkarıp Set Niagara Variable (Float) düğümünü çağırın.
    • In Variable Name kutusuna tam olarak User.MuzikSiddeti yazın (Harf büyüklüklerine dikkat edin).
  3. Veri Ayrıştırması:
    • Event On UDP Message Received üzerinden gelen String'i Parse Into Array ile bölün.
    • Get (0) BEAT ise, Get (1) pinindeki değeri To Float yapın.
    • Arduino'dan gelen 0-4000 arası tepe değerini Map Range Clamped ile partikülün isteyeceği mantıklı bir boyuta (Örn: 0.1 ile 5.0 arası) oranlayıp, az önce oluşturduğumuz Set Niagara Variable düğümünün In Value pinine takın.

🚀 Atölye Tatbikatı: İnteraktif Konser Sahnesi

ARGE ekibinizle ses ve görseli muazzam bir ahenkle buluşturmanın tam vakti.

Laboratuvara bir hoparlör kurun ve bas frekansları yüksek bir elektronik müzik (EDM veya Cyberpunk müzikleri) açın. Sensörü hoparlöre yakın bir yere yerleştirin. Unreal Engine'deki sahneyi tam ekrana alın. Bass vuruşları (Beat) geldikçe, ekrandaki devasa Niagara partiküllerinin ritimle birebir aynı anda patladığını, küçülüp büyüdüğünü göreceksiniz. Bu, gençlere sadece oyun değil, canlı "Sahne Sanatları" ve "Etkileşimli Medya (Interactive Media)" tasarladıklarını en iyi şekilde hissettirecektir.
