Proje 32: Büyük Final

Beyin Bilgisayar Arayüzü (BCI) ile Sanal Gerçeklikte Telekinezi

🎯 Senaryo: Sadece Düşünerek Oynamak

Donanım geliştirmenin en ileri noktası olan Beyin-Bilgisayar Arayüzleri (BCI), medikal araştırmalardan oyun sektörüne kadar devrim yaratıyor. Kullanıcı zihnini boşaltıp tamamen ekrandaki nesneye odaklandığında (Attention seviyesi arttığında), Unreal Engine bu nörolojik veriyi alacak ve fizik motorunu manipüle ederek objeyi yerçekimine karşı koyarak havaya kaldıracaktır!

🤖 1. Fiziksel Katman: Bluetooth ve Beyin Dalgaları

NeuroSky MindWave cihazı, verilerini Bluetooth üzerinden iletir. Arduino'ya bir HC-05 Bluetooth modülü bağlayarak (RX->TX, TX->RX) kulaklık ile Arduino'yu eşleştirmemiz gerekir. Arduino IDE'de Brain kütüphanesini kullanarak bu veriyi işliyoruz.

#include <SoftwareSerial.h>
#include <Brain.h>

SoftwareSerial btSerial(10, 11); // HC-05 Modülü
Brain brain(btSerial);

void setup() {
  Serial.begin(9600); // Unreal ile haberleşme
  btSerial.begin(57600); // NeuroSky Baud Rate
}

void loop() {
  if (brain.update()) {
    int odakSeviyesi = brain.readAttention();
    if (odakSeviyesi > 0) {
      Serial.print("FOCUS,");
      Serial.println(odakSeviyesi);
    }
  }
}

🟦 2. Blueprint (Unreal Engine) Telekinezi Mekaniği

  1. Event Tick üzerinden gelen veriyi Parse Into Array ile ayırın.
  2. Map Range Clamped ile 40-100 arası odaklanma değerini, 0-50000 arası bir "Z Ekseni Kuvveti"ne dönüştürün.
  3. Sahnedeki objenize Add Force düğümünü bağlayın.
  4. Accel Change (Kütleyi Yoksay) seçeneğini işaretleyerek objenin kütlesinden bağımsız olarak havaya kalkmasını sağlayın.
