ESP32 ve UDP Protokolü ile Wi-Fi Üzerinden Unreal Engine İletişimi

🎯 Senaryo: Sınırları Kaldırmak

Bugüne kadar yaptığımız tüm projelerde Arduino'yu bilgisayarımıza bir USB kablosuyla (Seri Port) bağlamak zorundaydık. Ancak gerçekçi bir VR (Sanal Gerçeklik) simülatörü veya hareketli bir Escape Room (Kaçış Odası) tasarlarken kablolar en büyük düşmanımızdır.

Bu projede, bilgisayarımızla aynı Wi-Fi ağına bağlı bir ESP32 kullanacağız. ESP32, üzerindeki bir butona basıldığında yerel ağ üzerinden (Modem aracılığıyla) bilgisayarımızın IP adresine UDP (User Datagram Protocol) paketi gönderecek. Unreal Engine bu paketi havadan yakalayıp oyundaki bir olayı tetikleyecek!




🤖 1. Fiziksel Katman: ESP32 Wi-Fi ve UDP Kodlaması

ESP32'nin gücü dahili Wi-Fi anteninde yatar. Test etmek için ESP32'nin Dijital 4 numaralı pinine basit bir buton bağlayın (Diğer bacağı GND'ye).

// ESP32 KODU: UDP Üzerinden Unreal'a Veri Gönderme
#include <WiFi.h>
#include <WiFiUdp.h>

// Wi-Fi Ağ Bilgileriniz (Laboratuvardaki modem)
const char* ssid = "Laboratuvar_WiFi";
const char* password = "Sifre1234";

// Unreal Engine Çalışan Bilgisayarın Yerel IP Adresi (CMD -> ipconfig)
const char* unrealIP = "192.168.1.100"; 
const int unrealPort = 8888; // Veriyi göndereceğimiz Port

WiFiUDP udp;
const int butonPin = 4;

void setup() {
  Serial.begin(115200);
  pinMode(butonPin, INPUT_PULLUP);

  // Wi-Fi'ye Bağlan
  WiFi.begin(ssid, password);
  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.print(".");
  }
  Serial.println("\nWiFi Baglandi!");
}

void loop() {
  // Butona basıldıysa
  if (digitalRead(butonPin) == LOW) {
    
    // UDP Paketini Hazırla ve Bilgisayara Gönder
    udp.beginPacket(unrealIP, unrealPort);
    udp.print("KABLOSUZ_TETIK");
    udp.endPacket();
    
    Serial.println("UDP Paketi Gonderildi!");
    delay(300); // Debounce (Spam koruması)
  }
}
💡 TCP mi, UDP mi?: Web siteleri eksiksiz veri indirmek için TCP kullanır. Ancak oyun motorları "Hız ve Düşük Gecikme (Low Ping)" için UDP kullanır. UDP paketleri hedefe ulaştı mı diye kontrol etmez, sadece fırlatır! Bu yüzden oyunlarda lag olmaz.

🟦 2. Blueprint (Unreal Engine) UDP Dinleyicisi

Unreal Engine'in standart sürümünde UDP dinlemek için genellikle ücretsiz Marketplace eklentileri (Örn: Socketeter veya UDP Messaging) kullanılır. En popüler ücretsiz Socket eklentilerinden birini kurduğunuzu varsayarak (veya yerleşik OSC pluginini kullanarak) portu nasıl dinleyeceğimizi görelim.




Adım Adım Bağlantılar (Örnek UDP Eklentisi Mantığı):

  1. Soketi Başlatmak: Oyun başladığında (Event BeginPlay), Bind UDP Socket veya Create UDP Server düğümünü çağırın.
    • Port: ESP32'de belirlediğimiz 8888 numarasını yazın.
  2. Veriyi Havada Yakalamak: Soket başarıyla açıldıysa, eklentinin size sağladığı Event On Message Received (veya On Data Received) olayını Blueprint ekranınıza ekleyin. (Bu, Event Tick kullanmaktan çok daha performanslıdır, sadece veri geldiğinde çalışır).
  3. Metne Çevirme: Ağ üzerinden gelen veriler genellikle "Byte Array" (0'lar ve 1'ler kümesi) olarak gelir. Bunu Bytes to String düğümü ile okunabilir metne çevirin.
  4. Tetikleme: Çıkan String değerini Equal (==) düğümü ile KABLOSUZ_TETIK metnine eşitleyip bir Branch'e bağlayın. Şart sağlandığında, karakterinizi zıplatabilir, bir havai fişek patlatabilir veya kapı açabilirsiniz!

🚀 Atölye Tatbikatı: Sınıfın Öbür Ucundan Oynamak

ARGE ekibiniz ESP32'yi bir Powerbank'e (Taşınabilir Batarya) bağlasın. Bilgisayarla hiçbir fiziksel bağlantıları kalmadığında, laboratuvarın öbür ucuna (hatta koridora) gidip butona basarak Unreal Engine'deki karakteri kablosuz olarak kontrol etmenin büyüsünü yaşasınlar.

Bu altyapı, ileride kuracağımız devasa Laser Tag (Lazer Savaşları) veya etkileşimli müze projelerinin omurgasını oluşturacaktır.
