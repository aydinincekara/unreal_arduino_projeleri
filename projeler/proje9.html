Proje 9: Gizli Geçit

Ağırlık Sensörü (Load Cell) ile Basınca Duyarlı Kapı Açma Mekanizması

🎯 Senaryo: Tapınak Bulmacası

Oyun senaryomuzda karakterimiz kilitli dev bir taş kapının önüne geliyor. Kapının açılması için "Tam olarak 150 gram" ağırlığında bir altın heykeli kaideye koyması gerekiyor. Biz bu senaryoyu gerçek dünyaya taşıyoruz!

Laboratuvarımızdaki tartı sistemine (Load Cell) 140 ile 160 gram arasında bir nesne konulduğunda, Unreal Engine'de taş kapı sinematik bir şekilde yukarı doğru açılacak.




🤖 1. Fiziksel Katman: Load Cell ve HX711

Ağırlık sensörleri (Load Cell) tek başına Arduino'ya bağlanamaz çünkü ürettikleri elektriksel değişim çok küçüktür (milivolt seviyesinde). Bu sinyali yükseltmek için HX711 Amplifikatör Modülü kullanacağız. Modülün DT (Data) pinini D3'e, SCK (Clock) pinini D2'ye bağlayalım. Ayrıca Arduino IDE'den "HX711 by Bogdan Necula" kütüphanesini kurmalısınız.

// ARDUINO KODU: HX711 ile Gramaj Okuma
#include "HX711.h"

const int LOADCELL_DOUT_PIN = 3;
const int LOADCELL_SCK_PIN = 2;

HX711 scale;

void setup() {
  Serial.begin(9600);
  scale.begin(LOADCELL_DOUT_PIN, LOADCELL_SCK_PIN);
  
  // Kalibrasyon Çarpanı (Kendi sensörünüze göre ayarlamalısınız)
  scale.set_scale(2280.f); 
  scale.tare(); // Başlangıçta tartıyı sıfırla (Dara al)
}

void loop() {
  // 5 okumanın ortalamasını alarak daha kararlı bir sonuç elde ediyoruz
  float agirlik = scale.get_units(5);
  
  // Eğer ağırlık sıfırın altındaysa 0 göster
  if(agirlik < 0) agirlik = 0;

  // Ağırlığı gram cinsinden Unreal Engine'e gönder
  Serial.println(agirlik);

  delay(100); // 10Hz veri akışı yeterlidir
}
💡 Kalibrasyon İpucu: Tartınızın doğru ölçtüğünden emin olmak için önce kodu scale.set_scale(); şeklinde yükselticisiz çalıştırın. Sensöre bilinen bir ağırlık (Örn: 100 gramlık cep telefonu) koyun. Ekranda okunan ham değeri 100'e bölerseniz sizin gerçek kalibrasyon çarpanınız (Örn: 2280.f) ortaya çıkar.

🟦 2. Blueprint (Unreal Engine) Kodlaması

Sahnenize bir kapı objesi (Static Mesh) ekleyin ve Blueprint (Actor) haline getirin. Kapının yavaş ve sinematik bir şekilde açılması için Unreal'ın güçlü aracı olan Timeline (Zaman Çizelgesi) düğümünü kullanacağız.




Adım Adım Bağlantılar:

  1. Ağırlık Kontrolü: Event Tick -> Read Line ile okuduğunuz String değeri To Float yapın.
  2. Hassas Şart (InRange): Değerin tam 150 gram olması çok zordur (sensör 150.2 gram okuyabilir). Bu yüzden eşitlik (==) yerine In Range (Float) düğümünü kullanın.
    • Min: 140.0
    • Max: 160.0
  3. Sinyali Yönetmek: In Range'in kırmızı (Bool) çıkışını bir Branch düğümüne bağlayın.
    • Branch True ise (Ağırlık doğru): Bir DoOnce düğümünden geçip Timeline'ın Play (İleri Sar) girişine bağlayın.
    • Branch False ise (Ağırlık yanlış): Başka bir DoOnce üzerinden Timeline'ın Reverse (Geri Sar - Kapıyı Kapat) girişine bağlayın. (İki DoOnce birbirini Reset'lemelidir).
  4. Kapı Animasyonu (Timeline): Blueprint'e sağ tıklayıp Add Timeline deyin (Adını KapiAnimasyon yapın).
    • Timeline'a çift tıklayıp içine girin. Bir Float Track (Değer izi) ekleyin.
    • 0. saniyeye bir anahtar (Key) ekleyip değerini 0 (Kapı Kapalı) yapın.
    • 2. saniyeye bir anahtar ekleyip değerini 300 (Kapı Z ekseninde 300 birim yukarı kalksın) yapın.
  5. Hareketi Uygula: Timeline'ın Update pininden kablo çekip Set Relative Location (Kapının konumunu ayarla) düğümünü bağlayın. Timeline'dan çıkan float değerini kapının Z eksenine bağlayın.
⚠️ DoOnce Neden Yine Çıktı?: Eğer DoOnce kullanmazsanız, ağırlık doğru olduğu sürece Tick event'i saniyede 60 kez Timeline'a "Play, Play, Play" komutu gönderir ve kapınız asla açılamaz (sürekli başa sarar).
