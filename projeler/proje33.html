Proje 33: DMX Işık Kontrolü

Unreal Engine ile Fiziksel Sahne Işıklarını (Art-Net) Yönetmek

🎯 Senaryo: Oyun Dünyasının Gerçek Işıkları

Konserlerde, tiyatrolarda ve modern sinema stüdyolarında ışıklar **DMX512** adı verilen endüstriyel bir protokolle yönetilir. Unreal Engine 5, yerleşik DMX eklentisi sayesinde bir "Işık Şefi Masası" gibi çalışabilir.

Sanal dünyamızda polis arabasının tepe lambaları yanıp söndüğünde, veya oyuncu kırmızı bir lav havuzunun yanından geçtiğinde, atölyenizin köşesine kurduğunuz devasa RGB Par LED spot ışıkları da Wi-Fi üzerinden (Art-Net protokolüyle) anında aynı renge bürünecektir. ESP32'yi kullanarak on binlerce dolarlık ticari DMX Node cihazlarının kendi donanımsal alternatifimizi üreteceğiz.




🤖 1. Fiziksel Katman: MAX485 Entegresi ve Art-Net

DMX sinyali donanımsal olarak RS485 standardını kullanır. ESP32'nin TX (Gönderim) pinini bir MAX485 / RS485 Modülüne bağlayarak 3.3V'luk sinyali tiyatro ışıklarının anlayacağı endüstriyel diferansiyel sinyale çevireceğiz. MAX485'in A ve B uçları (Data+ ve Data-), sahne ışığının XLR soketine girecektir.

// ESP32 KODU: Art-Net Node (Wi-Fi'den DMX Sinyaline Çevirici)
#include <WiFi.h>
#include <ArtnetWifi.h> // Art-Net Kütüphanesi
#include <LXESP32DMX.h> // ESP32 DMX Kütüphanesi

// Ağ Ayarları
const char* ssid = "Laboratuvar_WiFi";
const char* password = "Sifre1234";

ArtnetWifi artnet;
const int dmxTxPin = 17; // MAX485 Modülünün DI (Data In) Pinine

// ArtNet paketi geldiğinde tetiklenecek fonksiyon
void onDmxFrame(uint16_t universe, uint16_t length, uint8_t sequence, uint8_t* data) {
  // Gelen 512 kanallı veriyi donanımsal DMX çıkışına yaz
  for (int i = 0; i < length; i++) {
    ESP32DMX.setSlot(i + 1, data[i]);
  }
}

void setup() {
  Serial.begin(115200);
  
  WiFi.begin(ssid, password);
  while (WiFi.status() != WL_CONNECTED) { delay(500); }
  
  // DMX Gönderimini Başlat (TX Pin 17)
  ESP32DMX.startOutput(dmxTxPin);

  // Art-Net dinleyiciyi başlat ve gelen paketi onDmxFrame'e yönlendir
  artnet.begin();
  artnet.setArtDmxCallback(onDmxFrame);
}

void loop() {
  // Wi-Fi üzerinden sürekli Art-Net paketlerini dinle
  artnet.read();
}
💡 Art-Net Nedir?: DMX kablosunu IP paketlerinin (Wi-Fi veya LAN) içine saran evrensel bir protokoldür. Unreal Engine doğrudan kabloyla DMX gönderemez; Art-Net (UDP IP) olarak ağa fırlatır, bizim kurduğumuz ESP32 düğümü (Node) bu ağ paketini yakalayıp gerçek kablolu DMX sinyaline dönüştürür.

🟦 2. Unreal Engine DMX Entegrasyonu

Motor ayarlarından DMX Engine ve DMX Protocol eklentilerini (Plugins) aktif edip motoru yeniden başlatın.




Adım Adım Kurulum:

  1. DMX Library Oluşturma: İçerik çekmecesinde sağ tıklayıp DMX -> DMX Library oluşturun.
    • Fixtures (Cihazlar): Kütüphanenin içine girip fiziksel ışığınızın özelliklerini (Örn: 3 Kanallı - Kırmızı, Yeşil, Mavi) tanımlayan bir "Fixture Type" oluşturun.
    • Patching (Adresleme): Bu ışığı "Universe 1, Channel 1" adresine yamalayın (Patch).
  2. Protokol Ayarları: Proje ayarlarında (Project Settings) DMX Plugin sekmesini bulun. Output Port (Çıkış Portu) oluşturun ve protokolü Art-Net seçip Hedef IP adresi olarak ESP32'nizin IP adresini girin.
  3. Blueprint ile Sinyal Göndermek:
    • Level Blueprint'i açın. Event Tick veya bir Buton tetikleyicisi kullanın.
    • Send DMX düğümünü çağırın.
    • DMX Library pinine oluşturduğunuz kütüphaneyi seçin.
    • Fixture Patch pinine ışığınızı seçin.
    • Make DMX Attribute Values düğümü ile Renk/Parlaklık (Örn: Red: 255, Green: 0, Blue: 0) değerlerini girin.
⚠️ Pixel Mapping: Unreal Engine'de tek tek renk yazmak yerine "Pixel Mapping" özelliğini kullanabilirsiniz. Ekrana bir kamera veya kutu koyduğunuzda, Unreal o kutunun içindeki oyun dünyası piksellerini analiz edip o anki ortam rengini otomatik olarak DMX üzerinden fiziksel ışıklara gönderir!

🚀 Atölye Tatbikatı:ARGE Prodüksiyon Stüdyosu

geliştirici takımınızla tasarladığınız donanım ve yazılımları bu projeyle birleştirerek eksiksiz bir Sanal Prodüksiyon (Virtual Production) Volume'ü inşa edin.

Laboratuvardaki masaları boşaltın. Ortaya güçlü bir DMX Par LED (Spot) yerleştirin. Öğrencilerden, oyun içindeki karakterin eline sanal bir meşale veya ışın kılıcı vermelerini isteyin. Karakter kılıcı salladıkça, etrafa yayılan dinamik ışık (Dynamic Lighting) analiz edilip DMX protokolüyle fiziksel odadaki spot ışığına aktarılacaktır. Artık oyunlar sadece ekranda değil, odanın tam içinde yaşanıyor!
