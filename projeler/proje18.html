Proje 18: Fiziksel Nişangah

Lazer ve Fotodirenç ile Raycast (Line Trace) Silah Mekaniği

🎯 Senaryo: Lazer ile Sanal Dünyayı Vurmak

Nişancı (Shooter) oyunlarında merminin nereye gideceğini hesaplamak için Unreal Engine Line Trace (Işın İzleme/Raycast) yöntemini kullanır. Silahın namlusundan görünmez bir lazer çıkar, çarptığı ilk objenin bilgisini bize getirir.

Bu projede sanal lazere fiziksel bir tetikleyici ekliyoruz. Masamızdaki hedef tahtasının ortasında duran LDR (Fotodirenç) sensörüne gerçek bir lazer işaretleyici (Laser Pointer) tutulduğunda, Unreal Engine'deki silahımız ateş edecek ve sanal hedefleri vuracaktır.




🤖 1. Fiziksel Katman: LDR ve Keskin Işık Tespiti

Proje 5'te LDR'yi ortam ışığını ölçmek için (Gece/Gündüz) kullanmıştık. Lazerin LDR üzerine düşürdüğü ışık, ortam ışığından çok daha keskin ve şiddetlidir. LDR'yi bir 10K direnç ile Voltaj Bölücü (Voltage Divider) olarak bağlayıp A0 analog pininden okuyacağız. 

// ARDUINO KODU: Lazer İsabet Algılama
const int ldrPin = A0;

// Odanın normal aydınlığına göre bu eşik değerini değiştirebilirsiniz.
// Lazer tam sensöre vurduğunda değer genellikle 850-950 arasına fırlar.
const int isabetEsigi = 800; 

void setup() {
  Serial.begin(9600);
}

void loop() {
  int isikSiddeti = analogRead(ldrPin);

  // Lazer LDR'ye isabet ettiyse!
  if (isikSiddeti > isabetEsigi) {
    // Unreal Engine'e "VURULDU" sinyali gönder
    Serial.println("HIT");
    
    // Taramalı tüfek gibi saniyede 10 kere algılamasın diye yarım saniye bekle
    delay(500); 
  }
  
  delay(10); // Hızlı tarama için kısa bekleme
}
💡 Kalibrasyon İpucu: Gündüz güneş alan bir odadaysanız LDR zaten 800 değerine ulaşabilir. Bu durumda LDR'nin etrafına siyah kartondan ufak bir boru (namlu/siperlik) yaparak sadece tam karşıdan gelen lazeri görmesini sağlayabilirsiniz.

🟦 2. Blueprint (Unreal Engine) Kodlaması

Karakterimizin (veya silahımızın) Blueprint dosyasına girelim. Arduino'dan "HIT" sinyali geldiğinde silahın ucundan hedefe doğru bir çizgi (Line Trace By Channel) çizeceğiz.




Adım Adım Bağlantılar:

  1. Sinyali Yakalama: Event Tick üzerinden Read Line ile okunan metni Trim yapın. Çıkan sonucu Equal (String) düğümü ile HIT kelimesine eşitleyin. Sonucu bir Branch'e bağlayın.
  2. Işın İzlemeyi Başlat (Line Trace): Branch True olduğunda Line Trace By Channel düğümünü çağırın. Bu düğümün iki kritik girişi vardır: Başlangıç noktası (Start) ve Bitiş noktası (End).
  3. Matematik (Merminin Rotası):
    • Karakterinizin kamerasını (veya silah namlusunu) referans olarak sahneye çekin.
    • Ondan Get World Location (Kameranın konumu) düğümünü bağlayın. Bunu Line Trace'in Start pinine bağlayın.
    • Yine kameradan Get Forward Vector (Kameranın baktığı yön) düğümünü çekin. Bu yön vektörünü Multiply (Vector * Float) düğümü ile silahınızın menziline (Örn: 5000) çarpın.
    • Çıkan sonucu Start konumuyla toplayın (Add Vector). Bunu Line Trace'in End pinine bağlayın.
  4. Vurulan Obje İle Etkileşim: Line Trace düğümünün Out Hit (Vurulan yer) pininden kablo çekip Break Hit Result deyin. Çıkan Hit Actor pinini alıp Apply Damage (Hasar ver) veya Destroy Actor (Yok et) düğümlerine bağlayarak sanal düşmanları indirebilirsiniz!
⚠️ Işını Görmek İçin: Başlangıçta merminin nereye gittiğini göremeyebilirsiniz. Line Trace düğümündeki Draw Debug Type ayarını For Duration yaparsanız, silah ateşlediğinde kırmızı lazer çizgisinin (Raycast) ekranda çizildiğini göreceksiniz.
