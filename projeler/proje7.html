Proje 7: Fiziksel Direksiyon

MPU6050 İvmeölçer ile Blueprint Karakter Yönlendirme

🎯 Senaryo: Kendi Uçuş Simülatörümüz

Unreal Engine'de karakter kontrolü klavye (WASD) veya gamepad (Thumbstick) üzerinden Axis Mapping (Eksen Haritalama) ile yapılır. Bu projede, masamızdaki MPU6050 (İvmeölçer/Jiroskop) sensörünü bir uçak löyesi gibi kullanacağız. Sensörü sağa yatırdığımızda uçağımız sağa yatacak (Roll), öne eğdiğimizde uçağımız aşağı dalacak (Pitch).

İlk defa iki veriyi (X ve Y ekseni eğimleri) aynı anda okuyup, bunları Unreal Engine içerisinde virgüllerinden ayıracağız (String Parsing).




🤖 1. Fiziksel Katman: Arduino Kodu (I2C Haberleşme)

MPU6050 sensörü Arduino ile I2C protokolü üzerinden haberleşir. Bağlantılar: VCC->5V, GND->GND, SDA->A4, SCL->A5. İşleri kolaylaştırmak için Arduino IDE üzerinden Adafruit_MPU6050 ve Adafruit_Sensor kütüphanelerini kurmanız gerekmektedir.

// ARDUINO KODU: MPU6050 Eksen Verilerini Paketleme
#include <Wire.h>
#include <Adafruit_MPU6050.h>
#include <Adafruit_Sensor.h>

Adafruit_MPU6050 mpu;

void setup() {
  Serial.begin(9600);
  // MPU6050'yi başlatmayı deniyoruz
  if (!mpu.begin()) {
    while (1) {
      delay(10);
    }
  }
}

void loop() {
  // Sensörden ivme, jiroskop ve sıcaklık verilerini al
  sensors_event_t a, g, temp;
  mpu.getEvent(&a, &g, &temp);

  // İvme değerleri m/s^2 cinsindendir. Genelde -10 ile +10 arasında değişir.
  float egimX = a.acceleration.x; 
  float egimY = a.acceleration.y;

  // ÇOKLU VERİ PAKETLEME: "X,Y\n" formatında gönderiyoruz
  Serial.print(egimX);
  Serial.print(",");
  Serial.println(egimY); // İkinci verinin sonuna println (Enter) atıyoruz!
  
  delay(20); // 50Hz veri akışı
}

🟦 2. Blueprint (Unreal Engine) Kodlaması

Sahnemizde kontrol edebildiğimiz bir aktör (Pawn) oluşturalım, içine bir "Static Mesh" (Uçak veya Küp modeli) ekleyelim. Gelen "5.2,-3.4" tarzındaki metni iki ayrı sayıya böleceğiz.




Adım Adım Bağlantılar:

  1. Veriyi Parçalamak (Parsing): Event Tick -> Read Line ile metni okuyun. Sarı String pininden kablo çekin ve Parse Into Array düğümünü bulun.
    • Delimiter (Ayırıcı): Bu kutuya virgül , yazın. Bu düğüm, metni virgüllerden kırparak bir liste (Array) oluşturur.
  2. Dizi (Array) Elemanlarını Almak: Parse Into Array düğümünün çıkışındaki kare pininden kablo çekin ve Get (a copy) düğümünü iki kez çağırın.
    • Birinci Get düğümünün indeksini 0 yapın (Bu bizim X ivmemiz).
    • İkinci Get düğümünün indeksini 1 yapın (Bu bizim Y ivmemiz).
    • Her ikisini de To Float ile ondalıklı sayıya çevirin.
  3. Optimizasyon ve Dönüştürme: Arduino'dan gelen -10 ile +10 arasındaki ivme değerlerini, uçuş rotasyonuna çevirmek için her iki değeri de ayrı ayrı Map Range Clamped düğümlerine bağlayın.
    • In Range A / B: -10.0 ve 10.0
    • Out Range A / B: -45.0 ve 45.0 (Uçak maksimum 45 derece yatsın)
  4. Aktörü Döndürmek: Event Tick'in beyaz akış kablosunu alın ve Set Actor Relative Rotation düğümüne bağlayın.
    • New Rotation pinine sağ tıklayıp Split Struct Pin deyin.
    • X ekseninden gelen değeri Roll (Yatma) eksenine bağlayın.
    • Y ekseninden gelen değeri Pitch (Eğilme) eksenine bağlayın.
💡 Array Index Hatası Almamak İçin: Bazen Arduino bağlantısı ilk başladığında eksik paketler (Sadece virgül olmadan "5") gönderebilir. Parse Into Array işleminden hemen sonra bir Length düğümü ile dizinin eleman sayısının 2'ye eşit (==) olup olmadığını bir Branch ile kontrol etmek, oyunun çökmesini (Out of Bounds hatası) engeller!
