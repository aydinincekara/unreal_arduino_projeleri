Rotary Encoder ile UMG Silah Tekerleği (Weapon Wheel) Yönetimi

🎯 Senaryo: Envanteri Döndürmek

Oyunlarda karakterin silahlarını veya eşyalarını hızlıca seçmesini sağlayan dairesel menülere "Weapon Wheel" (Silah Tekerleği) denir. Normalde bu işlem farenin tekerleği (Scroll) ile yapılır.

Bu projede sonsuz dönebilen fiziksel bir Enkoder (KY-040) kullanarak, bu dijital tekerleği fiziksel olarak çevireceğiz. Üstelik menüde istediğimiz silahın üzerine geldiğimizde, enkoderin üzerine tıklayarak (buton özelliği) o silahı doğrudan kuşanacağız.




🤖 1. Fiziksel Katman: KY-040 Rotary Encoder

Rotary Encoder'lar potansiyometrelere benzer ama sınırları yoktur, sonsuza kadar dönerler ve her bir "tık" hareketinde dijital sinyal üretirler. Modülün CLK pinini Dijital 2'ye, DT pinini Dijital 3'e, SW (Buton) pinini ise Dijital 4'e bağlayalım. VCC 5V'a, GND GND'ye gider.

// ARDUINO KODU: Yön ve Tıklama Algılama
const int clkPin = 2;
const int dtPin = 3;
const int swPin = 4;

int sonClkDurumu;
int simdikiClkDurumu;

void setup() {
  Serial.begin(9600);
  pinMode(clkPin, INPUT);
  pinMode(dtPin, INPUT);
  pinMode(swPin, INPUT_PULLUP); // Buton için dahili direnç
  
  sonClkDurumu = digitalRead(clkPin);
}

void loop() {
  // Düğmenin dönüp dönmediğini kontrol et
  simdikiClkDurumu = digitalRead(clkPin);
  
  if (simdikiClkDurumu != sonClkDurumu && simdikiClkDurumu == 1) {
    // DT pini farklıysa SAĞA dönmüştür
    if (digitalRead(dtPin) != simdikiClkDurumu) {
      Serial.println("NEXT"); // Sonraki Silah
    } 
    // DT pini aynıysa SOLA dönmüştür
    else {
      Serial.println("PREV"); // Önceki Silah
    }
  }
  
  sonClkDurumu = simdikiClkDurumu;

  // Üzerine tıklandı mı? (Seçimi Onayla)
  if (digitalRead(swPin) == LOW) {
    Serial.println("SELECT");
    delay(300); // Buton sekmesini engelle
  }
}
💡 Enkoder Mantığı (A ve B Fazı): Enkoderler içlerinde iki farklı iletken tarak barındırır. Sağa dönerken önce A (CLK), sonra B (DT) temas eder. Sola dönerken tam tersi olur. Kodumuzdaki mantık, "Hangisi önce temas etti?" sorusunun cevabıdır.

🟦 2. Blueprint (Unreal Engine) Kodlaması

Unreal Engine tarafında SeciliSilahIndex adında bir Integer (Tam sayı) değişkenine ihtiyacımız var. (Örn: 0: Tabanca, 1: Tüfek, 2: Pompalı, 3: Bıçak).




Adım Adım Bağlantılar:

  1. Gelen Yönü Ayıklamak: Event Tick üzerinden Read Line ile okunan metni Trim yapıp Switch on String düğümüne bağlayın. (Pinler: NEXT, PREV, SELECT).
  2. Silah İndeksini Değiştirmek:
    • NEXT (Sağ): SeciliSilahIndex değişkenini alın, Add (+) düğümüyle 1 artırın. Eğer sayı 3'ü geçerse (Sadece 4 silahımız var), tekrar 0'a döndürmek için bir Branch ekleyin.
    • PREV (Sol): SeciliSilahIndex değişkenini alın, Subtract (-) düğümüyle 1 eksiltin. Eğer sayı 0'ın altına (-1) düşerse, en sonuncu silaha (3) eşitleyin.
  3. UI (Arayüz) Güncellemesi: İndeks her değiştiğinde ekrandaki Widget'a haber gönderin (Örn: Seçili silahın resmini büyüt veya etrafını parlat).
  4. Seçimi Onaylamak: SELECT pininden kablo çekin. Switch on Int düğümünü kullanarak SeciliSilahIndex değerine göre karakterin elindeki silah modelini (Static Mesh) değiştirin!
⚠️ Dairesel Menü Mantığı: İndekslerin 0'ın altına düşünce sona gitmesi ve sonu geçince başa dönmesi işlemine "Dairesel Limit (Wrap Around)" denir. Profesyonel UI tasarımcılarının tekerlekli menülerde en çok kullandığı matematiksel fonksiyondur.

🚀 Atölye Tatbikatı: Araç Telsiz Frekansı

Bu mekaniği sadece silah seçimi için kullanmak zorunda değilsiniz. Atölyedeki gençlerden oyun içine bir araba eklemelerini isteyin.
