Proje 11: Sanal Sandık, Gerçek Kilit

Servo Motor ile Unreal'dan Fiziksel Kilit Açma Mekanizması

🎯 Senaryo: Sanal Ganimet, Fiziksel Ödül

Oyunlarda sandık açma (Loot) mekaniği, oyunculara en çok tatmin veren anlardan biridir. Bu deneyimi 4. duvarı yıkarak gerçek hayata taşıyoruz. Unreal Engine'de karakterimiz bir hazine sandığına yaklaşıp etkileşim tuşuna ('E') bastığında, oyun motoru Arduino'ya "Aç" komutu gönderecek.

Arduino, üzerindeki mikro SG90 Servo motoru 90 derece döndürerek masamızda bulunan fiziksel ahşap bir kutunun mandalını serbest bırakacak ve kutu açılacaktır.




🤖 1. Fiziksel Katman: SG90 Servo Motor

Servo motorların üç kablosu vardır: Kahverengi (GND), Kırmızı (5V) ve Turuncu (Sinyal). Sinyal kablosunu Arduino'nun PWM (~) destekli bir pinine, örneğin Pin 9'a bağlayacağız.

// ARDUINO KODU: Unreal'dan Gelen Komutla Servo Döndürme
#include <Servo.h> // Servo kontrol kütüphanesi

Servo kilitMotoru;
const int servoPin = 9;

void setup() {
  Serial.begin(9600);
  kilitMotoru.attach(servoPin); // Motoru 9. pine ata
  
  // Başlangıçta kilit kapalı pozisyonda (0 derece) olsun
  kilitMotoru.write(0); 
}

void loop() {
  // Unreal Engine'den komut gelip gelmediğini kontrol et
  if (Serial.available() > 0) {
    char komut = Serial.read();
    
    // 'A' (AÇ) komutu geldiyse motoru 90 dereceye getir (Kilidi aç)
    if (komut == 'A') {
      kilitMotoru.write(90);
    }
    // 'K' (KAPAT) komutu geldiyse motoru 0 dereceye getir (Kilitle)
    else if (komut == 'K') {
      kilitMotoru.write(0);
    }
  }
}
⚠️ Güç Yönetimi: SG90 küçük bir motor olsa da, eğer çok zorlanan veya sıkışan ağır bir kilidi açmaya çalışırsa Arduino'nun 5V pininden aşırı akım çekerek bilgisayarın USB portunu dondurabilir. Motor zorlanıyorsa harici bir 5V adaptör kullanmayı unutmayın!

🟦 2. Blueprint (Unreal Engine) Kodlaması

Sahnemizde BP_Sandik adında bir Blueprint Actor oluşturalım. İçine bir sandık modeli ve bir Box Collision (Etkileşim Alanı) ekleyelim. Oyuncu bu kutunun içindeyken "E" tuşuna basarsa komut gönderilecek.




Adım Adım Bağlantılar:

  1. Etkileşimi Aktif Etmek: Sandığın içine oyuncu girdiğinde tuş basımlarını dinleyebilmemiz gerekir. On Component Begin Overlap (Box) düğümünden Enable Input (Girdiyi Etkinleştir) düğümünü çağırın ve Player Controller'ı bağlayın. Çıkıldığında ise On Component End Overlap üzerinden Disable Input ile kapatın.
  2. 'E' Tuşuna Basılması: Boş bir yere sağ tıklayıp Keyboard E (veya tanımladığınız bir Action Mapping) düğümünü çağırın. Bu düğümün Pressed pininden kablo çekin.
  3. Aç/Kapat Geçişi (Flip Flop): Sandığı aynı tuşla hem açıp hem kapatabilmek için Flip Flop düğümünü kullanın.
    • A Çıkışı (İlk Basış - Aç): Write String düğümünü bağlayın. String kutusuna A yazın. Ayrıca sanal sandığın kapağını açan animasyonu (Timeline ile) burada başlatabilirsiniz.
    • B Çıkışı (İkinci Basış - Kapat): Başka bir Write String düğümü bağlayın. String kutusuna K yazın.

🚀 Atölye Tatbikatı: Gerçek Ganimetler

Bu proje, atölyenizi ziyaret eden konuklar veya öğrenciler için muazzam bir "Wow Effect" (Şaşırtma Etkisi) yaratır. Projeyi daha eğlenceli hale getirmek için fiziksel kutunun içine gençlerin seveceği ufak ödüller (şeker, çıkartma vb.) koyabilirsiniz. Oyunda gizli bir bulmacayı çözüp sandığı bulan öğrenci, masasında fiziksel kutunun "tık" sesiyle açılmasıyla büyük bir tatmin yaşayacaktır.
