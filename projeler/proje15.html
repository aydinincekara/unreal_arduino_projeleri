Proje 15: Oksijen ve Hayatta Kalma

Fiziksel Su Seviye Sensörü ile UMG Oksijen Barı Yönetimi

🎯 Senaryo: Boğulma Mekaniği

Oyun dünyasında karakterin suyun altında ne kadar kalabileceğini belirleyen bir "Oksijen Barı" (Oxygen/Breath Bar) genellikle bir zamanlayıcıyla çalışır. Biz bu zamanlayıcıyı masamızdaki fiziksel sıvı miktarına bağlıyoruz.

Sensör suya çok az temas ettiğinde oksijen yavaş yavaş azalacak, sensör tamamen suya daldırıldığında ise oksijen hızla tükenecek ve sonunda karakter boğularak (Hasar alarak) ölecektir. Suden çıkarıldığında ise oksijen barı tekrar dolmaya başlayacaktır.


[Image of Arduino water level sensor wiring diagram]

🤖 1. Fiziksel Katman: Analog Su Seviye Sensörü

Su sensörleri üzerinde paralel bakır şeritler barındırır. Bu şeritler suyla temas ettiğinde direnç değişir. Sensörün S (Sinyal) pinini Arduino'nun A0 analog pinine, + pinini 5V'a, - pinini ise GND'ye bağlayın.

// ARDUINO KODU: Su Seviyesini Oku ve Gönder

const int suSensoriPin = A0;

void setup() {
  Serial.begin(9600);
}

void loop() {
  // Sensör değerini oku (Kuruyken 0, tamamen suyun içindeyken ~600-700 arası değer verir)
  int suSeviyesi = analogRead(suSensoriPin);
  
  // Ufak parazitleri yoksaymak için eşik (Threshold) belirliyoruz
  if(suSeviyesi < 10) {
    suSeviyesi = 0;
  }
  
  // Veriyi Unreal Engine'e gönder
  Serial.println(suSeviyesi);
  
  delay(50); // Veri akışını dengele (20 FPS)
}
⚠️ Laboratuvar Güvenliği (Elektroliz Uyarısı): Su sensörleri sıvı içinde elektrik akımı geçirdiği için zamanla bakır kısımlarında "korozyon" ve "elektroliz" (yeşerme) meydana gelir. Sensörü suyun içinde saatlerce bırakmayın. Test işlemi bittikten sonra bir peçete ile kurulamanız sensörün ömrünü uzatacaktır.

🟦 2. Blueprint (Unreal Engine) Kodlaması

Bu mekaniği kurmak için iki şeye ihtiyacımız var: Birincisi karakterin canını tutan değişkenler, ikincisi ise bunu ekranda gösterecek bir UMG Progress Bar (İlerleme Çubuğu).




Adım Adım Bağlantılar:

  1. Değişkenleri Hazırlama: Karakter Blueprint'inize girip MaxOxygen (Değer: 100.0) ve CurrentOxygen (Değer: 100.0) adında iki adet Float değişken oluşturun.
  2. Veri ve Tüketim Hızı: Event Tick üzerinden Read Line ile sensörden gelen su verisini okuyup Float'a çevirin.
    • Gelen bu veriyi Map Range Clamped düğümüne bağlayın.
    • In Range: 0 - 600 (Sensör sınırları)
    • Out Range: -5.0 (Suyun dışındayken saniyede 5 birim oksijen DOLSUN) ve 10.0 (Sensör tamamen sudayken saniyede 10 birim oksijen AZALSIN).
  3. Matematik İşlemi:
    • CurrentOxygen değişkenini alıp, az önce bulduğunuz hız değeriyle Subtract (-) (Çıkar) düğümüne sokun.
    • Sonucu Clamp (Float) düğümünden geçirin (Min: 0.0, Max: 100.0). Böylece oksijen 0'ın altına veya 100'ün üstüne çıkamaz.
    • Çıkan nihai sonucu tekrar Set CurrentOxygen düğümüyle kaydedin.
  4. Boğulma (Hasar) Kontrolü: Oksijen hesaplandıktan sonra bir Branch ile CurrentOxygen <= 0 mı diye kontrol edin. Eğer True ise, karaktere saniyede bir miktar hasar vermek için Apply Damage düğümünü kullanın!
💡 Delta Time (Optimizasyon): Event Tick bilgisayarınızın hızına (FPS) göre çalışır. Güçlü bir bilgisayarda oksijen çok hızlı tükenirken, yavaş bir bilgisayarda yavaş tükenir. Bunu engellemek için, çıkarma işlemi yapmadan önce eksilecek miktarı Event Tick'in Delta Seconds piniyle (Çarpma işlemi kullanarak) çarpmalısınız. Bu sayede süre FPS'ten bağımsız, gerçek saniyeye döner!

🚀 Atölye Tatbikatı: UI Oksijen Barı

Sistemin çalıştığını görmek için ekrana bir UI çizelim:

  1. Unreal'da sağ tıklayıp User Interface -> Widget Blueprint oluşturun (Adı: UI_Oxygen).
  2. İçine sol taraftaki paletten bir Progress Bar (İlerleme Çubuğu) sürükleyin. Rengini mavi yapın.
  3. Progress Bar'ın sağ tarafındaki Percent ayarının yanındaki Bind butonuna tıklayıp Create Binding deyin.
  4. Açılan kod ekranında, karakterinize Cast yapıp (Örn: Cast To ThirdPersonCharacter) onun CurrentOxygen değerini çekin. Bu değeri 100'e bölüp (Çünkü progress bar 0.0 ile 1.0 arası çalışır) çıkışa bağlayın.

Oyunu başlattığınızda, sensörü suya soktuğunuz anda ekrandaki mavi barın yavaşça eridiğini kendi gözlerinizle göreceksiniz!
