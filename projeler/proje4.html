Proje 4: Çift Yönlü İletişim

Dokunsal Geri Bildirim (Haptic Feedback) ve Hasar Mekaniği

🎯 Senaryo: Sanal Hasar, Gerçek Sarsıntı

Oyun dünyasının en önemli hislerinden biri "dokunsal geri bildirimdir" (Haptic Feedback). Unreal Engine sahnesindeki karakterimiz bir düşman mermisi yediğinde veya yüksek bir yerden düşüp hasar aldığında, oyun motoru Arduino'ya anlık bir "Sarsıntı" komutu gönderecek.

⚠️ Donanım Güvenliği (Çok Önemli): DC Titreşim motorları, bir LED'e göre çok daha fazla akım çeker. Motoru doğrudan Arduino'nun pinlerine bağlamak, anakartı yakabilir! Bu yüzden araya bir anahtar görevi görecek olan Transistör (Örn: 2N2222) veya bir Röle Modülü koymak zorundayız.



🤖 1. Fiziksel Katman: Arduino Kodu

Arduino, Unreal Engine'den 'H' (Hasar) karakteri gelip gelmediğini dinleyecek. 'H' karakteri geldiğinde motoru yarım saniye çalıştırıp geri kapatacak.

// ARDUINO KODU: Hasar Sinyalini Dinle
const int motorPin = 9; // Transistörün Base bacağına veya Röleye giden pin

void setup() {
  Serial.begin(9600); 
  pinMode(motorPin, OUTPUT); 
}

void loop() {
  // Unreal Engine'den gelen bir komut var mı kontrol et
  if (Serial.available() > 0) {
    char komut = Serial.read();
    
    // Eğer gelen komut 'H' (Hasar) ise:
    if (komut == 'H') {
      digitalWrite(motorPin, HIGH); // Motoru titreştir
      delay(300);                   // 300 milisaniye (0.3 sn) sarsıntı hissi
      digitalWrite(motorPin, LOW);  // Motoru durdur
    }
  }
}

🟦 2. Blueprint (Unreal Engine) Kodlaması

Unreal Engine'de karakterimizin bulunduğu Actor Blueprint'ini açalım. Karakterin hasar aldığını bildiren yerleşik düğümü kullanacağız.




Adım Adım Bağlantılar:

  1. Hasar Olayını Yakalamak: Blueprint ekranında boş bir yere sağ tıklayıp Event AnyDamage düğümünü çağırın. Bu düğüm, karakterinize oyunda herhangi bir yolla (Ateş, Düşme, Patlama) hasar verildiğinde tetiklenir.
  2. Görsel Uyarı (İsteğe Bağlı): Event AnyDamage'den bir kablo çekip Print String bağlayın ve ekrana "HASAR ALINDI!" yazdırın. (Sistemin çalıştığını test etmek için iyi bir yoldur).
  3. Sinyali Göndermek: Print String'den çıkan kabloyu Write String (veya kullandığınız Seri Port eklentisindeki karşılığı) düğümüne bağlayın.
    • Port: (Daha önce ArduinoPort değişkenine kaydettiğiniz port bağlantısını Target kısmına bağlayın).
    • String: Kutuya sadece H yazın.
💡 Deneme Tahtası: Karakterinizin hasar almasını test etmek için sahneye bir "Ateş" veya "Tuzak" kutusu (Trigger Box) koyun. Karakter içine girdiğinde Apply Damage düğümünü tetikleterek karaktere zarar verin. Masanızdaki motorun anında titrediğini göreceksiniz.

🚀 ARGE Ekibi İçin Meydan Okuma

Bu proje, sarmal müfredatta öğrendiğimiz bilgileri birleştirmek için harika bir fırsattır. Öğrencilerinizden şu geliştirmeleri yapmalarını isteyebilirsiniz:

  • Hasar Şiddeti: Event AnyDamage düğümünde alınan hasarın miktarı (Damage pin) yazar. Alınan hasar 10 ise ufak bir titreşim ('K' komutu), 50 ise çok güçlü bir titreşim ('B' komutu) gönderecek bir Branch (If) yapısı kurun.
  • Sağlık Barı: Projeyi daha önce HTML/CSS ile yaptığınız gibi, Unreal Engine UI (UMG) sistemiyle birleştirip ekrana bir Can Barı (Health Bar) çizin. Titreşimle aynı anda can barının da azalmasını sağlayın.
