Proje 26: Görsel Şov Yönetimi

OSC (Open Sound Control) Protokolü ile Endüstriyel Haberleşme

🎯 Senaryo: Profesyonel VJ (Visual Jockey) Konsolu

OSC, eski MIDI protokolünün modern ve ağ tabanlı (Wi-Fi/LAN) versiyonudur. Ses sentezleyicileri, ışık masaları ve Unreal Engine gibi devasa medya motorları birbirleriyle OSC üzerinden konuşur.

OSC mesajları, bilgisayarlardaki dosya dizinlerine benzer bir yapıdadır (Örn: /sahne/lazer/renk). Bu projede ESP32'mize bir potansiyometre (Slider) bağlayacağız. Slider'ı kaydırdığımızda ESP32, Wi-Fi üzerinden Unreal Engine'e standart bir OSC paketi gönderecek ve oyun sahnesindeki sis miktarını veya sahne ışıklarının parlaklığını milisaniyelik bir tepki süresiyle kontrol edeceğiz.




🤖 1. Fiziksel Katman: MicroOSC ile Veri Paketleme

Arduino IDE üzerinden OSC veya MicroOSC kütüphanesini kurmalıyız. ESP32'nin A0 (Örn: GPIO 36) pinine basit bir potansiyometre (Slider) bağlayın.

// ESP32 KODU: OSC Mesajı Oluşturma ve Gönderme
#include <WiFi.h>
#include <WiFiUdp.h>
#include <OSCMessage.h> // CNMAT OSC Kütüphanesi

const char* ssid = "Laboratuvar_WiFi";
const char* password = "Sifre1234";
// Unreal Engine PC IP ve Dinleme Portu
IPAddress unrealIP(192, 168, 1, 100); 
const unsigned int outPort = 8000; 

WiFiUDP Udp;
const int sliderPin = 36; // Analog pin

void setup() {
  Serial.begin(115200);
  WiFi.begin(ssid, password);
  while (WiFi.status() != WL_CONNECTED) { delay(500); }
}

void loop() {
  // Slider değerini oku (ESP32 analog çözünürlüğü 0-4095 arasıdır)
  int analogDeger = analogRead(sliderPin);
  
  // Unreal Engine'de kullanmak üzere 0.0 ile 1.0 arasında ondalıklı sayıya (Float) çevir
  float parlaklik = (float)analogDeger / 4095.0;

  // OSC Mesajını oluştur: Adres (URL gibi düşünün)
  OSCMessage msg("/sahne/isik/parlaklik");
  
  // Mesajın içine veriyi (Payload) ekle
  msg.add(parlaklik);

  // Mesajı UDP üzerinden gönder
  Udp.beginPacket(unrealIP, outPort);
  msg.send(Udp); 
  Udp.endPacket();
  msg.empty(); // Belleği temizle

  delay(20); // 50Hz güncelleme hızı
}
💡 OSC'nin Avantajı Nedir?: Düz UDP'de virgülleri sayarak (Get 0, Get 1) veriyi ayırıyorduk ve hata yapma ihtimalimiz yüksekti. OSC'de ise verinin bir adresi vardır. Sadece adresi sorarız: "Bana /sahne/isik/parlaklik verisini ver" deriz. Bu, devasa projelerde yüzlerce cihazı yönetmenin tek yoludur.

🟦 2. Blueprint (Unreal Engine) Yerleşik OSC Eklentisi

Unreal Engine 5'te OSC yerleşik (built-in) olarak gelir. Sadece Edit -> Plugins menüsünden OSC Plugin'i aktifleştirip motoru yeniden başlatmanız yeterlidir.




Adım Adım Bağlantılar:

  1. OSC Sunucusunu Başlatmak: Level Blueprint'te Event BeginPlay düğümüne Create OSC Server bağlayın.
    • Receive IP Address: 0.0.0.0 (Tüm ağlardan dinle demektir).
    • Port: Arduino'da yazdığımız 8000 numarasını girin.
    • Düğümden çıkan Server referansını bir Promote to Variable ile değişkene kaydedin ki silinmesin. Sonra bu değişkenden kablo çekip Bind Event to On OSC Message Received düğümünü ekleyin.
  2. Gelen Paketi Ayrıştırmak: Bind Event için yeni bir Custom Event (Örn: GelenOSC) oluşturun. Bu event tetiklendiğinde size bir Message pini verecektir.
    • Message pininden kablo çekin ve Get OSC Message Address düğümünü çağırın.
    • Adresi Convert OSC Address To String düğümü ile metne çevirip bir Switch on String düğümüne bağlayın.
    • Switch'in pin adını /sahne/isik/parlaklik yapın.
  3. Veriyi (Float) Çıkarmak: Switch tetiklendiğinde, kurala uyan mesaj gelmiş demektir.
    • Yine Message pininden kablo çekin ve Get OSC Message Float at Index düğümünü çağırın. Index 0 kalsın.
    • Çıkan bu 0.0 - 1.0 arasındaki Float değerini, sahnenizdeki bir Spot Işığının (SpotLight) Intensity değerini (Set Intensity) değiştirmek için kullanın (Map Range Clamped ile 0-5000 arasına oranlayabilirsiniz).

🚀 Atölye Tatbikatı: Prodüksiyon Masası (DJ/VJ Konsolu)

geliştiricileriniz için bu proje, teknoloji ile sanatın buluştuğu noktadır. Odanın ışıklarını kapatın. Büyük bir ekrana Unreal Engine'den görseli yansıtın.

Gençlerden, üzerine 4-5 adet kaydırmalı potansiyometre (Slider) ve renkli butonların olduğu bir VJ (Visual Jockey) ahşap masası inşa etmelerini isteyin. Biriyle sis yoğunluğunu, diğeriyle lazerlerin dönüş hızını, bir diğeriyle kameranın odak (Depth of Field) ayarını değiştirsinler. Gerçek zamanlı bir elektronik müzik eşliğinde fiziksel dünyadan sanal bir partiyi yönettiklerinde, endüstriyel standart olan OSC'nin gücünü ömür boyu unutmayacaklardır.
