Proje 36: Otonom Robot Radarı

İnsansız Araçların (İKA) Konumlarını Unreal Engine Üzerinde Anlık Takip Etmek

🎯 Senaryo: Komuta Kontrol Merkezi

Fabrikalarda dolaşan otonom kargo taşıyıcılarını (AGV) veya savunma sanayiindeki insansız kara araçlarını (İKA) düşünün. Operatörler bu araçları pencereden bakarak değil, önlerindeki dijital haritalar ve radar ekranları (SCADA) üzerinden takip ederler.

Bu projede, üzerine ESP32 taktığımız fiziksel bir robot araba, hareket ettikçe tahmini X (İleri/Geri), Y (Sağ/Sol) ve Yaw (Yönelim Açısı) değerlerini Wi-Fi üzerinden Unreal Engine'e fırlatacak. Oyun motorumuzdaki sahnede, laboratuvarın tepeden görünen bir haritası olacak ve robotun 3 boyutlu dijital ikizi gerçek dünyayla birebir aynı hareketleri sergileyecektir.




🤖 1. Fiziksel Katman: Odometri ve Konum Verisi (UDP)

Gerçek bir projede X ve Y koordinatları tekerleklere bağlı enkoderlerden (Tekerleğin kaç tur döndüğünü sayan optik sensörler) ve bir pusula modülünden elde edilir. Kavramı test etmek için ESP32'de basit bir matematiksel konum simülasyonu hazırlayalım ve bu koordinatları UDP üzerinden paketleyelim.

// ESP32 KODU: Robot Konum Verisi Gönderimi
#include <WiFi.h>
#include <WiFiUdp.h>

const char* ssid = "Laboratuvar_WiFi";
const char* password = "Sifre1234";
const char* unrealIP = "192.168.1.100";
const int unrealPort = 8888;

WiFiUDP udp;

// Robotun Başlangıç Koordinatları (cm cinsinden)
float robotX = 0.0;
float robotY = 0.0;
float robotAngle = 0.0; // Yönelim Açısı (0-360)

void setup() {
  Serial.begin(115200);
  WiFi.begin(ssid, password);
  while (WiFi.status() != WL_CONNECTED) { delay(500); }
}

void loop() {
  // Gelişmiş projelerde buradaki değerler tekerlek enkoderi, GPS 
  // veya Kapalı Alan Konumlandırma (UWB) sensörlerinden okunur.
  // Simülasyon için robotu yavaşça çapraz hareket ettiriyoruz:
  robotX += 0.5; 
  robotY += 0.2;
  robotAngle = 15.0; 

  // Veriyi Paketle (Format: RADAR, X, Y, Açı)
  // Örnek Çıktı: "RADAR,120.5,45.2,15.0"
  String veriPaketi = "RADAR," + String(robotX) + "," + String(robotY) + "," + String(robotAngle);
  
  udp.beginPacket(unrealIP, unrealPort);
  udp.print(veriPaketi);
  udp.endPacket();

  delay(50); // Saniyede 20 kez konum güncellemesi
}
💡 Gerçek Odometri (Odometry): Tekerleğin çevresini ölçüp (Örn: 20 cm), motorun bir turunda robotun 20 cm ilerlediğini hesaplama işlemine "Ölü Hesaplama (Dead Reckoning)" denir. Profesyonel İKA donanımlarının çekirdek matematiği budur.

🟦 2. Unreal Engine Dijital İkiz (Digital Twin) Aktörü

Oyun dünyasında 1 Birim (Unit), genellikle 1 Santimetreye (cm) eşittir. ESP32'den gelen 120 değerini doğrudan 120 cm olarak sahnedeki modele yansıtacağız.




Adım Adım Bağlantılar:

  1. Paketi Okuma ve Filtreleme:
    • Event On UDP Message Received düğümünü Parse Into Array ile virgüllerden ayırın.
    • Get (0) pininin RADAR kelimesine eşit olup olmadığını Branch ile doğrulayın.
  2. Konum Vektörünü Oluşturma:
    • Get (1) (X değeri) ve Get (2) (Y değeri) pinlerini alıp To Float yapın.
    • Bu değerleri bir Make Vector düğümünün X ve Y girişlerine takın. Z (Yükseklik) girişine robotun sahnedeki mevcut yüksekliğini (Get Actor Location Z) verebilirsiniz ki robot yerin altına girmesin.
  3. Açı (Rotator) Oluşturma:
    • Get (3) (Açı değeri) pinini To Float yapıp, bir Make Rotator düğümünün Yaw (Z ekseni etrafında dönüş) girişine takın.
  4. Aktörü Güncelleme:
    • Sahnede bulunan Robot Aktörünüzün (Örn: BP_OtonomRobot) referansını çekin.
    • Bundan bir kablo uzatarak Set Actor Location And Rotation düğümünü çağırın.
    • Make Vector'den çıkan konumu ve Make Rotator'dan çıkan açıyı ilgili pinlere bağlayın. Robot artık fiziksel eşiyle aynı konumda!
⚠️ Titreme Giderme (Interpolation): Ağ paketleri bazen gecikebilir ve robot ekranda ışınlanıyormuş (teleport) gibi atlayarak ilerleyebilir. Daha profesyonel bir görünüm için, "Set Actor Location" kullanmak yerine, VInterp To (Vector Interpolation) düğümünü kullanarak hedef koordinata yumuşak bir şekilde süzülmesini sağlayabilirsiniz.

🚀 Atölye Tatbikatı: Mayın Tarlası / Labirent Keşfi

Odanın ortasına mukavvalardan veya tahtalardan bir labirent kurun. Unreal Engine sahnemizde, bu labirentin sadece zemin planı (Floor Plan) olsun ve Unreal'daki kamerayı tam tepeden (Top-Down View) bakacak şekilde ayarlayın. Ekip üyelerinden biri otonom robotu veya RC aracı labirentin içine bıraksın. Diğer üyeler ekrandaki radar arayüzüne bakarak, robotun labirentin neresinde olduğunu milimetrik olarak takip etsin. Bu, modern dronların (UAV) ve kargo robotlarının endüstriyel takip merkezlerinde kullanılan sistemin tamamen aynısıdır!
