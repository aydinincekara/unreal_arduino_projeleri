Proje 23: Akıllı Telefon Entegrasyonu

ESP32 Web Server Üzerinden Cep Telefonu ile Sanal Ev/Oyun Kontrolü

🎯 Senaryo: Odanın Hakimi Sizsiniz

Oyun içi dünyalar giderek akıllı ev konseptleriyle bütünleşiyor. Bu projede, ESP32 modülünü bir "Web Sunucusuna" (Web Server) dönüştürüyoruz. ESP32, belleğinde basit bir HTML arayüzü barındıracak.

Aynı Wi-Fi ağına bağlı cep telefonunuzdan ESP32'nin IP adresine girdiğinizde karşınıza "Işığı Aç" ve "Işığı Kapat" butonları çıkacak. Telefondan butona tıkladığınızda, ESP32 Unreal Engine'e bir komut fırlatacak ve oyun motorundaki odanın ışıkları fiziksel dünyadan verilen bu mobil emirle yanıp sönecek!




🤖 1. Fiziksel Katman: ESP32 Web Server Kodlaması

Bu kodda hiçbir fiziksel butona ihtiyacımız yok. Kullanıcının arayüzü cep telefonu olacak. ESP32 sadece bir köprü görevi görecek. WebServer.h kütüphanesi ile telefona HTML gönderecek, gelen tıklamalara göre UDP üzerinden Unreal'a sinyal yollayacağız.

// ESP32 KODU: Web Server ve UDP Köprüsü
#include <WiFi.h>
#include <WebServer.h>
#include <WiFiUdp.h>

const char* ssid = "Laboratuvar_WiFi";
const char* password = "Sifre1234";
const char* unrealIP = "192.168.1.100"; 
const int unrealPort = 8888;

WebServer server(80); // 80 numaralı standart web portu
WiFiUDP udp;

// Telefondan görülecek basit HTML arayüzü
const char* htmlArayuz = R"rawliteral(
<!DOCTYPE html><html><head>
<meta name="viewport" content="width=device-width, initial-scale=1">
<style>
  body { text-align: center; font-family: Arial; background-color: #121212; color: white; padding-top: 50px; }
  .btn { padding: 20px 40px; font-size: 24px; margin: 10px; border-radius: 10px; border: none; cursor: pointer; color: white; }
  .btn-ac { background-color: #2ecc71; }
  .btn-kapat { background-color: #e74c3c; }
</style></head><body>
  <h1>Sanal Ev Kontrol Paneli</h1>
  <button class="btn btn-ac" onclick="fetch('/ac')">Işığı Aç</button><br>
  <button class="btn btn-kapat" onclick="fetch('/kapat')">Işığı Kapat</button>
</body></html>
)rawliteral";

void setup() {
  Serial.begin(115200);
  WiFi.begin(ssid, password);
  
  while (WiFi.status() != WL_CONNECTED) {
    delay(500); Serial.print(".");
  }
  // Telefondan girilecek IP adresini ekrana yazdır!
  Serial.println("\nTelefondan şu IP'ye girin:");
  Serial.println(WiFi.localIP());

  // Web Sunucu Yönlendirmeleri (Routing)
  server.on("/", []() {
    server.send(200, "text/html", htmlArayuz);
  });
  
  server.on("/ac", []() {
    udpGonder("ISIK_AC");
    server.send(200, "text/plain", "Sinyal Gitti");
  });
  
  server.on("/kapat", []() {
    udpGonder("ISIK_KAPAT");
    server.send(200, "text/plain", "Sinyal Gitti");
  });

  server.begin();
}

void loop() {
  // Sunucuya gelen talepleri dinle
  server.handleClient();
}

// UDP Gönderme Fonksiyonu
void udpGonder(String mesaj) {
  udp.beginPacket(unrealIP, unrealPort);
  udp.print(mesaj);
  udp.endPacket();
}
💡 IP Adresi Nedir?: ESP32'yi çalıştırdığınızda Arduino Serial Monitör'de 192.168.1.35 gibi bir numara çıkacaktır. Cep telefonunuzun web tarayıcısına (Chrome/Safari) tam olarak bu numarayı yazmanız yeterlidir.

🟦 2. Blueprint (Unreal Engine) Kodlaması

Sahnemizde bir oda tasarlayalım ve tavana bir Point Light (Nokta Işık) ekleyelim. Bu ışığı Level Blueprint'e referans olarak alacağız.




Adım Adım Bağlantılar:

  1. Gelen Sinyali Yakalamak: Proje 21'deki gibi Event On UDP Message Received düğümünü kullanıp Bytes verisini Bytes to String ile metne dönüştürün.
  2. Yönlendirme (Switch): Gelen metni Trim yapıp Switch on String düğümüne sokun. Pinleri ISIK_AC ve ISIK_KAPAT olarak ikiye ayırın.
  3. Işığı Kontrol Etmek:
    • Sahnedeki Point Light referansınızı alıp ondan bir kablo çekin ve Set Visibility (Görünürlüğü Ayarla) düğümünü çağırın.
    • ISIK_AC pinini bu düğüme bağlayın ve New Visibility kutucuğunu işaretleyin (True).
    • Tekrar bir Set Visibility düğümü çağırın. Bu kez ISIK_KAPAT pinini bağlayın ve kutucuğu boş bırakın (False).
