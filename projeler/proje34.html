Proje 34: Sanal Kamera Eşleştirme (Tracker)

MPU6050 ve ESP32 ile Gerçek Zamanlı In-Camera VFX Donanımı

🎯 Senaryo: Sınırları Aşan Kameralar

Yeşil perde (Green Screen) dönemi kapanıyor, LED ekran (Volume) dönemi başlıyor. Bir oyuncuyu dijital bir ormanın önünde çekerken, fiziksel kamera (örneğin Sony veya Canon) hareket ettiğinde, arkadaki dijital ormanın perspektifinin de kusursuz bir şekilde değişmesi gerekir. Buna Camera Tracking (Kamera Takibi) denir.

Sarmal müfredatımızın bu projesinde, içine ESP32 ve MPU6050 koyduğumuz ufak bir 3D baskı kutuyu, gerçek bir kameranın flaş kızağına (Hot Shoe) monte edeceğiz. Kamera sağa, sola veya yukarı döndüğünde bu açısal veriler (Pitch, Roll, Yaw) Unreal Engine'deki profesyonel sinema kamerasına (Cine Camera Actor) anında iletilecek.




🤖 1. Fiziksel Katman: UDP Açı (Euler) Veri Gönderimi

I2C üzerinden bağlanan MPU6050'nin en büyük problemi "Gimbal Lock" ve zamanla kayma (Drift) yapmasıdır. Daha profesyonel bir sonuç için kodlamada DMP (Digital Motion Processor) verilerini kullanabilir veya BNO055 sensörü tercih edebilirsiniz. Biz MPU6050'nin ham açılarını saniyede 60 kez Unreal Engine'e UDP olarak fırlatacağız.

// ESP32 KODU: Kamera Takip (Camera Tracker) Sistemi
#include <WiFi.h>
#include <WiFiUdp.h>
#include <Wire.h>
#include <Adafruit_MPU6050.h>
#include <Adafruit_Sensor.h>

const char* ssid = "Laboratuvar_WiFi";
const char* password = "Sifre1234";
const char* unrealIP = "192.168.1.100";
const int unrealPort = 8888;

WiFiUDP udp;
Adafruit_MPU6050 mpu;

void setup() {
  Serial.begin(115200);
  WiFi.begin(ssid, password);
  while (WiFi.status() != WL_CONNECTED) { delay(500); }
  
  if (!mpu.begin()) {
    Serial.println("MPU6050 Bulunamadi!");
    while (1) delay(10);
  }
  
  // Düşük gecikme ve yumuşatma için donanımsal filtre
  mpu.setFilterBandwidth(MPU6050_BAND_44_HZ);
}

void loop() {
  sensors_event_t a, g, temp;
  mpu.getEvent(&a, &g, &temp);

  // Gyro verilerini basit açılara (Pitch, Roll, Yaw) çevirme mantığı
  // (Not: Profesyonel projelerde Quaternion hesaplaması kullanılır)
  float pitch = a.acceleration.y * 10; // Basit oranlama
  float roll = a.acceleration.x * 10;
  float yaw = g.gyro.z * 10; // Yaw ekseni Gyro'dan alınır

  // Veriyi Paketle (Format: CAM,Pitch,Roll,Yaw)
  String veriPaketi = "CAM," + String(pitch) + "," + String(roll) + "," + String(yaw);

  udp.beginPacket(unrealIP, unrealPort);
  udp.print(veriPaketi);
  udp.endPacket();

  // 60 FPS yayın hızı (yaklaşık 16ms)
  delay(16); 
}
💡 Kalibrasyon İpucu: Fiziksel sensörler dünyayla tam olarak hizalı başlamaz. Oyunculuk başlamadan önce kamerayı düz bir zemine koyup sıfırlama (Tare) işlemi yapacak bir buton entegre etmek sisteminizi çok daha güvenilir kılacaktır.

🟦 2. Unreal Engine CineCameraActor Entegrasyonu

Oyun motorunda sıradan bir karakter kamerası yerine, lens distorsiyonu (bozulması), odak uzaklığı (Focal Length) ve alan derinliği (Depth of Field) ayarlanabilen sinematografik bir Cine Camera Actor kullanacağız.




Adım Adım Blueprint Ağı:

  1. Gelen UDP Paketini Ayrıştırmak: Event On UDP Message Received düğümü ile veriyi Bytes to String yapıp Parse Into Array (Ayırıcı: virgül) ile bölün.
  2. Doğrulama: Get (0) pininin CAM kelimesine eşit olup olmadığını bir Branch ile kontrol edin.
  3. Verileri İşlemek:
    • Get (1) (Pitch), Get (2) (Roll) ve Get (3) (Yaw) düğümlerini To Float'a çevirin.
    • Sanal ve fiziksel dünyadaki X, Y, Z eksenleri genellikle farklıdır. Çıkan değerleri doğru eksenlere oturacak şekilde bir Make Rotator düğümüne bağlayın. (Gerekirse değerleri eksi ile çarparak (Multiply -1) yönleri tersine çevirin).
  4. Kamerayı Döndürmek:
    • Sahnede bulunan Cine Camera Actor referansınızı Event Graph'a çekin.
    • Bundan bir kablo çıkararak Set Actor Rotation düğümünü çağırın ve Make Rotator'dan çıkan değeri buraya takın.
