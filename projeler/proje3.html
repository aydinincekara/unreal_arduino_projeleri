Proje 3: Zamanın Kontrolü

Potansiyometre ile Unreal'da Global Time Dilation (Zamanı Bükme)

🎯 Senaryo: Fiziksel Matrix Etkisi

Oyun motorlarındaki fiziksel simülasyonların (düşen nesneler, patlamalar, yürüyen karakterler) hızı tek bir değişkene bağlıdır. Unreal Engine'de buna Global Time Dilation denir. Normal hızı 1.0'dır. Eğer bunu 0.1 yaparsanız oyun ağır çekime girer, 2.0 yaparsanız her şey iki kat hızlı hareket eder.

Bu projede masamıza basit bir potansiyometre (ayarlı direnç) kuracağız. Oyuncular bu düğmeyi çevirerek anlık olarak oyunun zaman akışını değiştirecekler.




🤖 1. Fiziksel Katman: Arduino Kodu

Potansiyometrenin sağ ve sol bacaklarını 5V ve GND pinlerine, orta bacağını ise A0 (Analog 0) pinine bağlıyoruz. Buradan 0 ile 1023 arasında bir değer okuyacağız.

// ARDUINO KODU: Potansiyometre Verisini Gönder
void setup() {
  Serial.begin(9600); 
}

void loop() {
  // A0 pininden değeri oku (0 - 1023 arası)
  int potDegeri = analogRead(A0);
  
  // Unreal Engine'de zamanı tamamen durdurmamak için ufak bir hile yapıyoruz.
  // 0 gelirse oyun donar, bu yüzden değerin altına sınır koyuyoruz (Örn: en az 10 gelsin).
  if(potDegeri < 10) potDegeri = 10;
  
  // Okunan veriyi Seri Porta yaz ve Alt Satıra in (println ZORUNLU)
  Serial.println(potDegeri); 
  
  // Titremeleri (Jitter) önlemek için ufak bir bekleme
  delay(20); 
}

🟦 2. Blueprint (Unreal Engine) Kodlaması

Gelen bu 0-1023 arası veriyi doğrudan Time Dilation'a bağlarsak oyun motoru çöker (zaman 1000 kat hızlanamaz). Bu yüzden gelen veriyi Unreal'da Map Range Clamped düğümüyle daraltacağız.




Adım Adım Bağlantılar:

  1. Veriyi Okumak: Event Tick üzerinden Read Line düğümüyle Arduino'dan gelen metni alıyoruz. Sarı (String) çıkışı To Float düğümüyle ondalıklı sayıya çevirin.
  2. Değerleri Dönüştürmek (Mapping): Çıkan bu Float kablosunu Map Range Clamped düğümüne bağlayın. Bu muazzam düğüm iki aralığı birbirine oranlar.
    • In Range A: 10 (Minimum potansiyometre değeri)
    • In Range B: 1023 (Maksimum potansiyometre değeri)
    • Out Range A: 0.1 (En ağır çekim, normalin %10'u)
    • Out Range B: 2.0 (Oyunun 2 kat hızlı hali)
  3. Zamanı Bükmek: Map Range Clamped düğümünün çıkışını Set Global Time Dilation düğümünün Time Dilation pinine bağlayın. Son olarak Tick event'inizin beyaz (Exec) kablosunu bu düğüme takın.
💡 Neden "Clamped" (Kelepçeli) Sürüm?: "Map Range Unclamped" kullanırsanız, sensörde oluşabilecek anlık bir parazit değeri sınırların dışına taşırır. Clamped sürümü, değer 1023'ü aşsa bile çıkışın 2.0'ı geçmesini fiziksel olarak engeller. Bu bir güvenlik (optimizasyon) önlemidir.

🚀 Atölye Tatbikatı

Mekaniği test etmek için sahneye dönen objeler, zıplayan toplar veya havada uçuşan partikül efektleri (Niagara) ekleyin. Play'e basın ve masadaki potansiyometreyi yavaşça sola çevirin.

Geliştirme Görevi: Zaman yavaşladığında seslerin (müziklerin) de perde değiştirmesi (Pitch kalınlaşması) gerekir. Öğrencilerinizden Set Global Pitch Modulation düğümünü araştırarak aynı potansiyometre verisiyle oyunun arka plan müziğini de ağır çekim hissiyatına uydurmalarını isteyin!
