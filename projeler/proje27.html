Proje 27: Gerçek Dünya Verileri

Web API'leri ve JSON Parsing ile Dünyayı Oyuna Çekmek

🎯 Senaryo: Yaşayan Bir Metaverse

Eskiden sensörleri odamızın sıcaklığını ölçmek için kullanıyorduk (Proje 16). Ancak bir uçağın uçuş rotasını, İstanbul'un anlık trafik durumunu veya uzaydaki Uluslararası Uzay İstasyonunun (ISS) konumunu fiziksel sensörlerle ölçemeyiz. Bunun yerine, bu verileri sağlayan devasa sunuculara (API) internet üzerinden istek (HTTP GET Request) atarız.

Bu projede, ESP32 internete bağlanıp ücretsiz bir hava durumu servisinden (Open-Meteo) canlı sıcaklık verisini bir JSON (JavaScript Object Notation) dosyası olarak indirecek, içinden sadece "Sıcaklık" değerini cımbızla çekecek ve kablosuz olarak Unreal Engine 5'e yollayacak.




🤖 1. Fiziksel Katman: HTTP İstemci ve ArduinoJson

İnternetten gelen veriler genellikle karmaşık parantezler silsilesi (JSON) halindedir. Bu veriyi kolayca çözebilmek için Arduino IDE üzerinden dünyanın en popüler IoT kütüphanelerinden biri olan ArduinoJson kütüphanesini (Benoît Blanchon) kurmanız zorunludur.

// ESP32 KODU: Web API'den Veri Çekme ve UDP ile Gönderme
#include <WiFi.h>
#include <HTTPClient.h>
#include <WiFiUdp.h>
#include <ArduinoJson.h>

const char* ssid = "Laboratuvar_WiFi";
const char* password = "Sifre1234";
const char* unrealIP = "192.168.1.100";
const int unrealPort = 8888;

// Open-Meteo API URL'si (İstanbul Koordinatları)
// Tarayıcınıza bu linki yapıştırırsanız gelen ham JSON verisini görebilirsiniz.
String apiUrl = "https://api.open-meteo.com/v1/forecast?latitude=41.01&longitude=28.97¤t_weather=true";

WiFiUDP udp;

void setup() {
  Serial.begin(115200);
  WiFi.begin(ssid, password);
  while (WiFi.status() != WL_CONNECTED) { delay(500); }
  Serial.println("WiFi Baglandi!");
}

void loop() {
  // Eğer Wi-Fi bağlantısı kopsa diye her döngüde kontrol et
  if (WiFi.status() == WL_CONNECTED) {
    HTTPClient http;
    http.begin(apiUrl);
    int httpResponseCode = http.GET(); // Veriyi Çek

    if (httpResponseCode == 200) { // 200: Başarılı (OK)
      String payload = http.getString();
      
      // JSON Belgesini Ayrıştır (Parse)
      DynamicJsonDocument doc(1024);
      deserializeJson(doc, payload);
      
      // JSON ağacındaki "current_weather"ın içindeki "temperature" değerini al
      float sicaklik = doc["current_weather"]["temperature"];
      
      // Unreal Engine'e Gönder
      udp.beginPacket(unrealIP, unrealPort);
      udp.print("ISTANBUL_ISI," + String(sicaklik));
      udp.endPacket();
      
      Serial.println("Gönderilen Sıcaklık: " + String(sicaklik));
    }
    http.end();
  }
  
  // Gerçek Web API'lerini saniyede 60 kere sorgularsanız IP'niz banlanır (DDoS sanırlar).
  // Bu yüzden 10 saniyede bir veri çekmek idealdir.
  delay(10000); 
}
⚠️ Sunucu Limitleri (Rate Limiting): Açık kaynaklı ücretsiz API'ler dakika başına kısıtlamalar koyarlar. delay(10000) komutunu silerseniz sunucu sizin kötü niyetli bir bot olduğunuzu düşünüp laboratuvarınızın ağını bloklayabilir!

🟦 2. Blueprint (Unreal Engine) Şehir Hologramı

Oyun sahnemizin ortasında, İstanbul'u temsil eden devasa bir Text Render (3 Boyutlu Metin) veya bir siberpunk reklam panosu (Widget in 3D Space) olduğunu düşünelim. Gelen veriyi bu tabelalara canlı yazdıracağız.




Adım Adım Bağlantılar:

  1. Gelen Paketi Yakalamak: Event On UDP Message Received ile paketi Bytes to String yapın.
  2. Ayrıştırmak: Metni Parse Into Array (Ayırıcı: virgül) düğümüne sokun.
  3. Anahtar Kelime Doğrulaması: Get(0)'ın ISTANBUL_ISI olup olmadığını bir Branch ile kontrol edin.
  4. 3D Metni Güncellemek: Branch True olduğunda;
    • Get(1) (Gelen sıcaklık değeri) düğümünü alın.
    • Sahnede bulunan Text Render aktörünüzün referansını çekin.
    • Bundan kablo çıkarıp Set Text düğümünü çağırın.
    • Gelen sayıyı Format Text düğümü (Örn: İstanbul Anlık Sıcaklık: {Derece} °C) ile birleştirerek Set Text düğümüne bağlayın.
