Proje 10: RFID ile Gizli Odaya Giriş

Gerçek Yetki Kartı ile Sanal Kapı ve Kilit Sistemleri (Erişim Kontrolü)

🎯 Senaryo: Üst Düzey Güvenlik (Access Denied)

Siberpunk veya bilimkurgu temalı oyunlarda oyuncu sık sık kilitli laboratuvar kapılarıyla karşılaşır. Bu engeli aşmak için normalde oyun içinde bir "Anahtar Kart" (Keycard) bulması gerekir. Ancak biz bu mekaniği kırıyoruz: Oyuncu oyunda kart aramak yerine, cüzdanındaki ulaşım kartını, otel anahtarını veya atölye yetki kartını fiziksel RFID okuyucuya tutacak. Unreal Engine bu kartın özel kimlik numarasını (UID) denetleyip yetkiyi onaylayacak.




🤖 1. Fiziksel Katman: RC522 RFID Okuyucu

RC522 modülü hızlı ve güvenilir SPI (Serial Peripheral Interface) protokolünü kullanır. Bağlantıları çok dikkatli yapılmalıdır (3.3V kullanır, 5V'a bağlarsanız modül yanar!).

  • SDA (SS) -> Pin 10
  • SCK -> Pin 13
  • MOSI -> Pin 11
  • MISO -> Pin 12
  • RST -> Pin 9
  • 3.3V -> 3.3V Pini (Kesinlikle 5V DEĞİL)
  • GND -> GND
// ARDUINO KODU: Kartın Kimlik Numarasını (UID) Unreal'a Gönderme
#include <SPI.h>
#include <MFRC522.h>

#define SS_PIN 10
#define RST_PIN 9

MFRC522 rfid(SS_PIN, RST_PIN);

void setup() {
  Serial.begin(9600);
  SPI.begin();       // SPI Haberleşmesini başlat
  rfid.PCD_Init();   // RFID modülünü başlat
}

void loop() {
  // Yeni bir kart yaklaştırılmadıysa başa dön
  if (!rfid.PICC_IsNewCardPresent() || !rfid.PICC_ReadCardSerial()) {
    return;
  }

  // Kart okunduğunda ID'sini tutacağımız boş bir metin oluşturuyoruz
  String uidString = "";

  // Kartın UID byte'larını yan yana ekleyip tek bir kelime yapıyoruz (Örn: A3B4C5D6)
  for (byte i = 0; i < rfid.uid.size; i++) {
    uidString += String(rfid.uid.uidByte[i], HEX);
  }

  // Harfleri BÜYÜK HARF yapıyoruz ki Unreal'da kıyaslaması kolay olsun
  uidString.toUpperCase();

  // Veriyi Unreal Engine'e gönder
  Serial.println(uidString);

  // Aynı kartı saniyede 10 kere okumasını engellemek için kartı uykuya al
  rfid.PICC_HaltA();
  
  // Fiziksel bir gecikme (Debounce)
  delay(1000); 
}
💡 Kendi Kartınızı Tanıtın: Önce Arduino'nun Seri Port Ekranı'nı açın. Okutmak istediğiniz (yetkili olacak) kartı cihaza yaklaştırın. Ekranda yazan kodu (Örn: F3A19B22) bir yere not edin. Unreal Engine'de bu kodu şifre olarak kullanacağız.

🟦 2. Blueprint (Unreal Engine) Kodlaması

Sahnenizde "KilitliKapı" adında bir Blueprint oluşturun. Tıpkı ağırlık sensörü (Load Cell) projesinde yaptığımız gibi kapı dönerek veya yana kayarak açılacak. Ancak bu kez sayıları (Float) değil, metinleri (String) karşılaştıracağız.




Adım Adım Bağlantılar:

  1. Kart Verisini Okumak: Event Tick üzerinden Read Line ile gelen String veriyi okuyun. Mavi pinden bir Trim düğümü bağlayın (Trim: metnin başındaki ve sonundaki görünmez boşlukları temizler).
  2. Şifre Kontrolü (String Compare): Trim edilmiş kablodan uzatıp Equal (String) (==) düğümünü çağırın.
    • Alt kısımdaki boşluğa Arduino'da not ettiğiniz Master Kartınızın kimliğini (Örn: F3A19B22) yazın.
  3. Karar Mekanizması: Eşitlik (Equal) düğümünden çıkan kırmızı kabloyu bir Branch düğümünün durum (Condition) pinine bağlayın.
    • Eğer kart DOĞRUYSA (True): Bir DoOnce üzerinden kapı açılma Timeline'ına gidin (Bkz. Proje 9). Ayrıca Play Sound düğümüyle "Access Granted" (Erişim Onaylandı) tarzı olumlu bir ses efekti çalın.
    • Eğer kart YANLIŞSA (False): Branch'in False çıkışına bir Print String (Ekrana "Geçersiz Kart!" yazdırın) veya "Access Denied" hata sesi çalan bir düğüm ekleyin.
⚠️ Önemli Güvenlik Detayı: Event Tick her karede okuma yaptığı için, Serial hattan bir veri akmıyorken (kart okutulmuyorken) Read Line boş bir metin ("") döndürecektir. Boş metin okunduğunda sistemin hata sesini sürekli (spam şeklinde) çalmaması için; Equal düğümünden önce Not Equal (String) (!=) düğümüyle gelen verinin "Boş Olmadığından" emin olun ve sistemi öyle test edin.
