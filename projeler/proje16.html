Proje 16: Çevresel Bağlantı

Gerçek Sıcaklık (DHT11) ile Niagara Partikül Sistemlerini Yönetmek

🎯 Senaryo: Odanız Soğuyunca Oyun da Soğusun

Video oyunlarında atmosferik efektler (kar, yağmur, toz bulutu, sis) Unreal Engine'in Niagara Particle System altyapısı ile oluşturulur. Normalde bu efektler sabit çalışır veya rastgele bir olayla tetiklenir. Biz bunu fiziksel dünyaya bağlayacağız.

Laboratuvardaki DHT11 Isı ve Nem sensörünü kullanarak ortam sıcaklığını ölçeceğiz. Eğer sıcaklık 20 derecenin üzerindeyse oyun güneşli olacak, 10-20 derece arasına düşerse yağmur yağacak, 10 derecenin altında ise kar fırtınası başlayacaktır!




🤖 1. Fiziksel Katman: DHT11 Sensörü

DHT11 dijital bir sensördür. VCC pinini 5V'a, GND'yi GND'ye, Data pinini ise Arduino'nun dijital Pin 7'sine bağlayın. Kodun çalışması için Arduino IDE'de Kütüphane Yöneticisi'nden (Library Manager) DHT sensor library by Adafruit paketini kurmanız gerekmektedir.

// ARDUINO KODU: Sıcaklık Verisini Okuyup Unreal'a Gönderme
#include "DHT.h"

#define DHTPIN 7     // Sensörün bağlandığı dijital pin
#define DHTTYPE DHT11   // Sensör tipi DHT 11

DHT dht(DHTPIN, DHTTYPE);

void setup() {
  Serial.begin(9600);
  dht.begin();
}

void loop() {
  // Sensörün okuması yaklaşık 250ms sürer, çok hızlı sorgulamayın
  delay(2000);

  // Sıcaklığı Celcius (Santigrat) cinsinden oku
  float sicaklik = dht.readTemperature();

  // Eğer okuma hatası varsa (sensör koptuysa vb.) atla
  if (isnan(sicaklik)) {
    return;
  }

  // Ondalıklı sıcaklık değerini gönder (Örn: 24.50)
  Serial.println(sicaklik);
}
⚠️ Önemli Not: DHT11 yavaş bir sensördür. Verileri 2 saniyede bir (delay(2000)) gönderir. Hızlı güncellemeler istiyorsanız oyun tarafında değerleri birbirine yumuşak geçişle (FInterp) bağlamanız gerekebilir, ancak hava durumu animasyonları için 2 saniye gayet yeterlidir.

🟦 2. Blueprint (Unreal Engine) Kodlaması

Unreal Engine tarafında BP_WeatherManager adında bir aktör oluşturun. Bu aktörün içine Components panelinden iki adet Niagara Particle System Component ekleyin. Birine kar efekti (VFX_Snow), diğerine yağmur efekti (VFX_Rain) tanımlayın. Auto Activate (Otomatik Başlat) özelliklerini kapatın.




Adım Adım Bağlantılar:

  1. Veriyi Float'a Çevirme: Event Tick -> Read Line ile okunan değeri alın ve To Float düğümü ile ondalıklı sayıya çevirin.
  2. Mantık Ağacı (Branching): Sıcaklık derecelerini kontrol etmek için ardışık Branch (If) düğümleri kullanacağız.
    • 1. Kontrol (Kar): Less Than (<=) düğümüyle sayının 10.0'dan küçük olup olmadığına bakın. True (Doğru) ise; Kar Niagara component'inden kablo çekip Activate (Çalıştır) deyin. Yağmur Niagara'sı için Deactivate (Kapat) deyin.
    • 2. Kontrol (Yağmur): 1. kontrolün False çıkışından devam edin. Sayının 20.0'dan küçük mü (<=) olduğuna bakın. True ise; Yağmur Niagara component'ini Activate yapın, Kar'ı Deactivate yapın.
    • 3. Kontrol (Güneşli): 2. kontrolün False çıkışı (Yani sıcaklık 20'den büyüktür) demek, havanın sıcak olduğu anlamına gelir. Hem Kar hem de Yağmur component'lerini Deactivate yapın.
💡 DoOnce Unutulmamalı: Aynı hava durumunu saniyede 60 kere aktive etmeye çalışmak performansı düşürür. Branch çıkışlarına yine birbirini resetleyen DoOnce düğümleri eklemeyi ihmal etmeyin!

🚀 Atölye Tatbikatı:Geliştirici Deneyimi

gençlerden oluşan ARGE ekibinizin bu projede gerçek dünyayla bağ kurmasını hızlandırmak için ufak bir hack yapın. Oda sıcaklığı genellikle sabit olacağı için hava değişimini test etmek zordur.

Geliştiricilerden DHT11 sensörüne buz aküsü (soğutucu jel) yaklaştırmalarını isteyin. Sıcaklık aniden 10 derecenin altına indiğinde oyunda birden kar fırtınasının kopması, kodun fiziksel dünyayla nasıl muazzam bir tepkimeye girdiğini saniyeler içinde kanıtlayacaktır.
