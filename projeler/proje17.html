Proje 17: Fiziksel Can Barı

Adreslenebilir WS2812B LED ile Dinamik Sağlık Yönetimi

🎯 Senaryo: Odanızdaki Oyun Arayüzü

Modern konsol kollarında (örn. PS4/PS5 DualSense) karakterin can durumunu gösteren LED ışıklar bulunur. Biz bu mantığı çok daha büyük bir ölçeğe taşıyacağız. Monitörünüzün arkasına veya klavyenizin önüne dizeceğiniz 10 piksellik bir WS2812B şeridi, oyun motorundaki can değişkeni (Health Variable) ile anlık senkronize çalışacak.




🤖 1. Fiziksel Katman: FastLED Kütüphanesi

Adreslenebilir LED'leri kontrol etmenin en profesyonel yolu FastLED kütüphanesidir (Arduino IDE'den indirebilirsiniz). LED şeridin VCC'sini 5V'a, GND'sini GND'ye, ortadaki DIN (Data In) bacağını ise araya bir 330 ohm direnç koyarak Arduino'nun Dijital 6 pinine bağlayın.

// ARDUINO KODU: Unreal'dan Gelen Can (0-100) Verisini LED'lere Yansıtma
#include <FastLED.h>

#define NUM_LEDS 10    // Şeridinizdeki LED sayısı (Örn: 10 adet)
#define DATA_PIN 6     // Veri pini

CRGB leds[NUM_LEDS];

void setup() {
  Serial.begin(9600);
  FastLED.addLeds<WS2812B, DATA_PIN, GRB>(leds, NUM_LEDS);
  FastLED.setBrightness(100); // Parlaklığı ayarla (0-255)
}

void loop() {
  // Serial'dan yeni bir veri gelene kadar bekle
  if (Serial.available() > 0) {
    
    // parseInt() komutu gelen metnin içindeki "sayıyı" direkt okur
    int canDegeri = Serial.parseInt(); 
    
    // Çöpleri temizlemek için satır sonu (newline) karakterini bekle/atla
    if (Serial.read() == '\n') {
      
      // Can değerini (0-100), yanacak LED sayısına (0-10) oranlıyoruz
      int yananLedSayisi = map(canDegeri, 0, 100, 0, NUM_LEDS);
      
      // Tüm LED'leri döngüyle tara
      for(int i = 0; i < NUM_LEDS; i++) {
        
        // Eğer sıradaki LED, yanması gereken LED sayısının içindeyse:
        if(i < yananLedSayisi) {
          // Renk Kodlaması:
          if(canDegeri > 50) {
            leds[i] = CRGB::Green;  // Can > %50: YEŞİL
          } else if(canDegeri > 20) {
            leds[i] = CRGB::Yellow; // Can > %20: SARI
          } else {
            leds[i] = CRGB::Red;    // Can <= %20: KIRMIZI
          }
        } 
        // Yanması gerekmiyorsa (Hasar alındıysa):
        else {
          leds[i] = CRGB::Black;    // SÖNDÜR
        }
      }
      
      // Değişiklikleri fiziksel şeride uygula
      FastLED.show(); 
    }
  }
}
⚠️ Güç Uyarısı: 10 adet LED'i Arduino'nun 5V pini besleyebilir. Ancak 30 veya 60 LED'lik uzun bir şerit kullanacaksanız, Arduino'nuz yanabilir! Uzun şeritler için harici bir 5V adaptör kullanmak zorundasınız.

🟦 2. Blueprint (Unreal Engine) Kodlaması

Unreal Engine tarafında Health (Float) adında bir değişkenimiz olacak. Maksimum canımız 100. Karakter hasar yediğinde veya can iksiri içtiğinde bu değeri güncelleyip Serial Port üzerinden Arduino'ya fırlatacağız.




Adım Adım Bağlantılar (Olay Güdümlü):

  1. Hasar Alma Olayı: Karakter Blueprint'inizde Event AnyDamage düğümünü çağırın. Bu düğüm ateş veya tuzaklardan tetiklenir.
  2. Matematik: Health değişkeninizi alın. Event AnyDamage'den gelen Damage (Hasar) pinini kullanarak Subtract (-) (Çıkar) düğümü ile canı düşürün. Sonucu Clamp (Float) ile 0 ve 100 arasına kilitleyin. Daha sonra çıkan sonucu Set Health düğümüyle kaydedin.
  3. Veriyi Metne Çevirme: Yeni can değerini göndermemiz lazım. Append düğümünü çağırın.
    • A Pini: Health değişkenini Float'tan Integer'a yuvarlayarak (Round düğümü) buraya takın.
    • B Pini: Kutuya tıklayıp Shift + Enter yaparak gizli "Alt Satıra İnme (\n)" karakterini ekleyin.
  4. Arduino'ya Gönderme: Append düğümünden çıkan metni Write String düğümüne bağlayın. (Bunu Event Tick'te DEĞİL, sadece Set Health düğümünden hemen sonra yapıyoruz ki seri port şişmesin).
