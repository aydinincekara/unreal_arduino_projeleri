Proje 28: Bulut Verisi

Firebase'den Çekilen Canlı Veriyi Unreal Engine'de Görselleştirme

🎯 Senaryo: Sınırları Aşan Oyunlar (Cloud Sync)

Modern oyunlar, verilerini oyuncunun bilgisayarında (Local) tutmak yerine bulutta (Cloud) saklar. Fortnite'taki canlı etkinlikler (Live Events) veya devasa oyun içi anonslar doğrudan bir veritabanından tetiklenir.

Bu projede, Google'ın sunduğu gerçek zamanlı veritabanı Firebase Realtime Database'i kullanıyoruz. Veritabanındaki /OyunDurumu/Duyuru kısmına web tarayıcımızdan "Sunucu Bakımı Başlıyor!" yazdığımız anda, ESP32 bunu anında algılayıp Unreal Engine'e iletecek ve oyunun ortasında devasa kırmızı bir bildirim (UI) olarak belirmesini sağlayacaktır.




🤖 1. Fiziksel Katman: Firebase Client Kodlaması

Arduino IDE Kütüphane Yöneticisinden Firebase ESP32 Client (veya Firebase Arduino Client Library for ESP8266 and ESP32) kütüphanesini kurmalısınız. Firebase konsolundan projenizi oluşturup, Realtime Database'i "Test Modunda" (Okuma/Yazma kuralları true) açmanız ve veritabanı URL'si ile gizli anahtarı (Secret) almanız gerekir.

// ESP32 KODU: Firebase'den Veri Okuma ve UDP ile Gönderme
#include <WiFi.h>
#include <FirebaseESP32.h>
#include <WiFiUdp.h>

// Wi-Fi Ayarları
const char* ssid = "Laboratuvar_WiFi";
const char* password = "Sifre1234";

// Firebase Ayarları
#define FIREBASE_HOST "projeniz-default-rtdb.firebaseio.com" 
#define FIREBASE_AUTH "SİZİN_FIREBASE_GİZLİ_ANAHTARINIZ" 

// Unreal Engine Ağ Ayarları
const char* unrealIP = "192.168.1.100";
const int unrealPort = 8888;

FirebaseData firebaseData;
WiFiUDP udp;

void setup() {
  Serial.begin(115200);
  
  WiFi.begin(ssid, password);
  while (WiFi.status() != WL_CONNECTED) { delay(500); }
  
  // Firebase'e Bağlan
  Firebase.begin(FIREBASE_HOST, FIREBASE_AUTH);
  Firebase.reconnectWiFi(true);
}

void loop() {
  // Firebase'deki "/OyunDurumu/Duyuru" yolundaki veriyi oku
  if (Firebase.getString(firebaseData, "/OyunDurumu/Duyuru")) {
    
    // Başarılıysa veriyi çek
    String gelenDuyuru = firebaseData.stringData();
    
    // Eğer boş değilse Unreal Engine'e paketle ve gönder
    if(gelenDuyuru.length() > 0) {
      udp.beginPacket(unrealIP, unrealPort);
      udp.print("BULUT_DUYURU," + gelenDuyuru);
      udp.endPacket();
      
      Serial.println("Gelen Veri: " + gelenDuyuru);
    }
  } else {
    Serial.println(firebaseData.errorReason());
  }
  
  // Her 5 saniyede bir veritabanını kontrol et
  delay(5000); 
}
💡 Bulut Maliyetleri: Firebase "Realtime Database", veriler değiştikçe çok hızlı tepki verir. Ancak saniyede 60 kere veri isterseniz Google size fatura çıkartabilir! Bu yüzden delay(5000) (5 saniye) döngüsü öğrenci projelerinde hayati önem taşır.

🟦 2. Blueprint (Unreal Engine) Global UI Sistemi

Oyun motorunda ekranda her an belirebilecek bir "Global Duyuru" arayüzü (Widget) hazırlayacağız.




Adım Adım Bağlantılar:

  1. UI Tasarımı: Yeni bir Widget Blueprint (UI_CloudAlert) oluşturun. Ekranın en üstüne (Top-Center) büyük ve kırmızı bir Text (Metin) ekleyin. Text kutusunu "Is Variable" olarak işaretleyin ki Blueprint'ten değiştirebilelim.
  2. Veriyi Yakalamak: UI_CloudAlert'in Event Graph'ında Event On UDP Message Received (veya kullandığınız ağ eklentisi) düğümünü bağlayın.
  3. Ayrıştırma (Parsing): Gelen veriyi String'e çevirip Parse Into Array ile virgüllerden ayırın.
    • Get (0)'ın BULUT_DUYURU olup olmadığını bir Branch ile kontrol edin.
    • Doğruysa, Get (1) pininden asıl metin verisini çekin.
  4. Ekrana Yazdırmak:
    • Text Variable'ınızın referansını Event Graph'a çekin.
    • Set Text (Text) düğümünü kullanın ve Get (1)'den gelen Firebase verisini buraya bağlayın.
    • (Opsiyonel): Yazı ekrana geldiğinde Play Sound 2D ile bir uyarı sesi (Ping!) çalmasını sağlayarak oyuncunun dikkatini çekin.
