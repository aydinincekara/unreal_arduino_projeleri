Unreal Engine'den Gerçek Fiziksel Rölelere (Relay) Komut Akışı

🎯 Senaryo: Sanaldan Fiziğe Hükmetmek

Bugüne kadar sensörlerden gelen verilerle Unreal Engine'deki olayları yönettik. Ancak Endüstri 4.0 ve akıllı ev (Smart Home) sistemlerinde oyun motorları aynı zamanda bir Kontrol Merkezi (SCADA) olarak kullanılır.

Bu projede işleri tersine çeviriyoruz! Unreal Engine içerisindeki sanal bir odada bulunan ışık düğmesine tıkladığınızda veya laboratuvarınızın 3 boyutlu dijital ikizinde bir vanayı çevirdiğinizde, oyun motoru Wi-Fi üzerinden (UDP) bir komut fırlatacak. Ağdaki ESP32 bu komutu yakalayacak ve üzerindeki fiziksel Röle (Relay) modülünü tetikleyerek gerçek dünyadaki bir masa lambasını, pervaneyi veya sireni çalıştıracaktır.




🤖 1. Fiziksel Katman: ESP32 UDP Dinleyicisi ve Röle Bağlantısı

Röleler, küçük voltajlarla (ESP32'nin 3.3V sinyali) büyük voltajlı ve akımlı cihazları açıp kapatmamızı sağlayan elektromekanik anahtarlardır. ESP32'nin D5 pinini, röle modülünün IN (Sinyal) pinine bağlayacağız.

🔥 ÖNEMLİ GÜVENLİK UYARISI!

Eğitim laboratuvarlarında ARGE ekibi ile çalışırken Röle'nin anahtarlama ucuna (COM ve NO pinlerine) ASLA doğrudan 220V Şebeke Elektriği (Priz elektriği) bağlamayın! Ölümcül elektrik çarpması riski vardır. Eğitim ve test aşamalarında daima 9V piller, 12V LED şeritler veya 5V DC motorlar kullanın.

// ESP32 KODU: Unreal Engine'den Gelen UDP Komutunu Dinleme ve Röle Tetikleme
#include <WiFi.h>
#include <WiFiUdp.h>

// Wi-Fi Ayarları
const char* ssid = "Laboratuvar_WiFi";
const char* password = "Sifre1234";

// UDP Ayarları
WiFiUDP udp;
const int localUdpPort = 8888; // ESP32'nin dinleyeceği port

// Röle Pini (D5)
const int relayPin = 5;

void setup() {
  Serial.begin(115200);
  
  // Röle pinini ÇIKIŞ olarak ayarla ve başlangıçta kapalı tut
  pinMode(relayPin, OUTPUT);
  digitalWrite(relayPin, LOW); // Röle modülünüz Low-Level Trigger ise HIGH yapın

  // Wi-Fi'ye Bağlan
  WiFi.begin(ssid, password);
  Serial.print("Baglaniyor...");
  while (WiFi.status() != WL_CONNECTED) { delay(500); Serial.print("."); }
  
  Serial.println("\nBaglandi! IP Adresi: ");
  Serial.println(WiFi.localIP()); // Unreal'da hedef olarak bu IP'yi yazacağız!

  // UDP Dinlemeyi Başlat
  udp.begin(localUdpPort);
  Serial.println("UDP Dinleniyor...");
}

void loop() {
  int packetSize = udp.parsePacket();
  
  // Eğer ağdan bir paket geldiyse
  if (packetSize) {
    char gelenMesaj[255];
    int len = udp.read(gelenMesaj, 255);
    if (len > 0) gelenMesaj[len] = 0; // Metnin sonunu belirle
    
    String komut = String(gelenMesaj);
    komut.trim(); // Boşlukları temizle
    
    Serial.println("Unreal'dan Gelen Komut: " + komut);

    // Komutlara Göre Röleyi Aç/Kapat
    if (komut == "LAMBA_AC") {
      digitalWrite(relayPin, HIGH);
      Serial.println("-> Röle AÇILDI");
    } 
    else if (komut == "LAMBA_KAPAT") {
      digitalWrite(relayPin, LOW);
      Serial.println("-> Röle KAPATILDI");
    }
  }
}
💡 IP Adresi Notu: ESP32'nin Seri Monitörde (115200 baud) yazdırdığı IP adresini (Örn: 192.168.1.45) bir kenara not edin. Blueprint'te paketi tam olarak bu adrese yollayacağız.

🟦 2. Blueprint (Unreal Engine) Karar ve Gönderim Merkezi

Oyun motorunda bir düğmeye basıldığında veya karakter bir "Trigger Box" alanına girdiğinde UDP üzerinden "LAMBA_AC" metnini ağa fırlatacağız.




Adım Adım Blueprint Ağı (Gönderim):

  1. Tetikleyici (Event): Bir UMG (Kullanıcı Arayüzü) oluşturun ve içine büyük bir buton ekleyin. Butonun On Clicked event'ini çağırın. (Alternatif olarak G tuşuna basılma event'ini de kullanabilirsiniz).
  2. Durum Kontrolü (Flip Flop): On Clicked pininden çıkıp bir Flip Flop düğümüne bağlayın. Bu düğüm, butona ilk tıklandığında (A) yolunu, ikinci tıklandığında (B) yolunu çalıştırır. (Aç / Kapat mantığı).
  3. Ağ Paketini Fırlatmak (Send UDP):
    • (A) çıkışından kablo çekin ve eklentinizin sunduğu Send UDP Message (veya Send String over UDP) düğümünü çağırın.
    • Target IP: ESP32'nizin IP adresi (Örn: 192.168.1.45).
    • Target Port: 8888 (ESP32 koduna yazdığımız port).
    • Message: LAMBA_AC yazın.
  4. Kapatma Sinyali:
    • Flip Flop'un (B) çıkışından kablo çekip kopyaladığınız ikinci bir Send UDP Message düğümüne bağlayın.
    • IP ve Port aynı kalacak. Sadece Message kutusuna LAMBA_KAPAT yazın.
⚠️ Ağ Eklentisi (Plugin) Gereksinimi: Unreal Engine çekirdeğinde veriyi ham UDP olarak dışarı atmak için C++ kodlarına ihtiyaç duyulur. Geliştiricilerinizin (Blueprint kullananların) işini kolaylaştırmak için Epic Marketplace'ten ücretsiz olarak "UDP Messaging" veya "TCP Socket Plugin" kurduğunuzdan ve String to Bytes dönüşümlerini doğru yaptığınızdan emin olun.

🚀 Atölye Tatbikatı: Acil Durum / Siren Sistemi

ekibinizi heyecanlandıracak mükemmel bir senaryo:

laboratuvarın duvarına, 12V ile çalışan döner bir polis/itfaiye sireni (tepe lambası) monte edin. Bu sirenin güç hattını ESP32 rölesi üzerinden geçirin.

Unreal Engine içerisinde karanlık, gizlilik (Stealth) odaklı bir görev hazırlayın. Eğer sanal dünyadaki karakteriniz güvenlik kameralarına yakalanırsa veya canı (HP) sıfıra düşüp oyun biterse (Game Over), oyun motoru anında "SIREN_CAL" komutunu göndersin. Laboratuvardaki gerçek kırmızı sirenler dönmeye ve ötmeye başladığında, siber-fiziksel sistemlerin oyuncu üzerindeki psikolojik ve sarmalayıcı (Immersive) etkisini tüm ekibiniz iliklerine kadar hissedecektir!
