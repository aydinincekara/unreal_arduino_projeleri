Proje 12: Biyometrik Etkileşim

Kalp Atış Hızı ile Oyun İçi Dinamik Müzik ve Gerilim Yönetimi

🎯 Senaryo: Korkunuz Oyunu Yönlendirsin

Oyun tasarımında "Adaptive Audio" (Uyarlanabilir Ses) oyuncu deneyimini zirveye taşıyan bir unsurdur. Normalde müzik temposu, ekranda düşman belirdiğinde veya karakterin canı azaldığında artar. Ancak bu projede, müziğin temposunu doğrudan oyuncunun gerçek hayattaki nabzına (BPM) bağlıyoruz!

Oyuncu korktuğunda veya heyecanlandığında artan kalp atışı, Unreal Engine'deki arka plan müziğinin perdesini (Pitch) ve hızını artırarak atmosferi daha da boğucu hale getirecektir.




🤖 1. Fiziksel Katman: Pulse Sensor

Kalp atış hızını ölçmek için tıbbi bir sensör olan Pulse Sensor kullanacağız. Sensörün Sinyal (S) pini Arduino'nun A0 analog pinine, diğer pinler ise 5V ve GND'ye bağlanır. En verimli ölçüm için Arduino IDE üzerinden PulseSensorPlayground kütüphanesini kurmanızı tavsiye ederiz.

// ARDUINO KODU: Dakikadaki Kalp Atışı (BPM) Hesaplama
#define USE_ARDUINO_INTERRUPTS true
#include <PulseSensorPlayground.h>

const int PulseWire = 0; // A0 pini
int Threshold = 550;     // Kalp atışının algılanma eşiği (Sensöre göre değişebilir)

PulseSensorPlayground pulseSensor;

void setup() {
  Serial.begin(9600);
  
  pulseSensor.analogInput(PulseWire);   
  pulseSensor.setThreshold(Threshold);   
  
  pulseSensor.begin(); // Sensörü başlat
}

void loop() {
  // Sensör bir nabız atışı (kalp atışı) algıladıysa
  if (pulseSensor.sawStartOfBeat()) {
    int myBPM = pulseSensor.getBeatsPerMinute();
    
    // Unreal Engine'e sadece nabız sayısını (Örn: 85) gönder
    if(myBPM > 40 && myBPM < 200) { // Anlamsız hatalı okumaları filtrele
      Serial.println(myBPM);
    }
  }
  
  delay(20);
}
⚠️ Ölçüm İpuçları: Pulse Sensörleri ortam ışığına ve parmağın baskısına çok duyarlıdır. Sensörü çok sıkı bantlamayın (kan akışı durur) veya çok gevşek tutmayın. Mümkünse sensörün üzerine şeffaf bir bant çekerek terden kısa devre yapmasını engelleyin.

🟦 2. Blueprint (Unreal Engine) Kodlaması

Unreal Engine sahnesine bir Audio Component (Ses Bileşeni) ekleyip gerilimli bir arka plan müziği (Ambient Sound) yerleştirin. Bu müziğin perdesini (Pitch) BPM değerine göre anlık değiştireceğiz.




Adım Adım Bağlantılar:

  1. Ses Dosyasını Ayarlamak: Sahnedeki Audio Component'e tıklayın. Özelliklerden müziğin Looping (Sürekli tekrarla) özelliğini aktif edin. Ardından bu bileşeni Level Blueprint'e sürükleyip referansını alın.
  2. Nabzı Okumak: Event Tick -> Read Line ile okunan String BPM değerini To Float düğümüyle dönüştürün.
  3. Müziğe Uyarlamak: Normal bir insanın dinlenik nabzı 60-80 arasıdır. Heyecanlandığında 120-140'lara çıkabilir. Float pinini Map Range Clamped düğümüne bağlayın.
    • In Range A (Sakin): 65.0
    • In Range B (Panik): 130.0
    • Out Range A (Normal Müzik Hızı): 1.0
    • Out Range B (Hızlanmış ve İnce Müzik Hızı): 1.6
  4. Müziğe Müdahale: Audio Component referansından bir kablo çekip Set Pitch Multiplier düğümünü çağırın. Map Range Clamped'dan çıkan oranı bu düğümün New Pitch Multiplier pinine bağlayın.
💡 Pitch Multiplier Ne Yapar?: Unreal'da sesin pitch (perde) değerini 1.0'ın üzerine çıkarmak, o sesi sadece inceltmekle (tizleştirmek) kalmaz, aynı zamanda daha hızlı çalmasını sağlar. Bu da tam olarak kalp atışı hızlanan birinin hissedeceği panik atmosferini yansıtır.

🚀 Atölye Tatbikatı ve UI (Arayüz) Eklentisi

Laboratuvar ekibindeki bir geliştiriciyi bilgisayarın başına oturtun ve sensörü parmağına takın. Oyunda üzerine aniden yaratıklar saldırtan (Proje 6'daki Jumpscare mantığını kullanabilirsiniz) bir test odası (Test Chamber) hazırlayın. Ekranda aniden düşman belirdiğinde veya karakter hasar aldığında, oyuncunun nabzının nasıl yükseldiğini ve müziğin buna nasıl eşzamanlı tepki verdiğini hep birlikte analiz edin.

Ek Görev: Ekrana (Widget Blueprint) kalp ritmini gösteren bir EKG grafiği veya kırmızı renkte yanıp sönen bir kalp ikonu ekleyin. Kalbin yanıp sönme hızını da aynı BPM değerinden besleyin!
