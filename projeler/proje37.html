Proje 37: Büyük Final

Dev Fiziksel Kaçış Odası (Escape Room) Simülasyonu

🎯 Senaryo: Siber-Fiziksel Ekosistem

Bir "Kaçış Odası" (Escape Room) hayal edin. Oyuncular odaya girer ve süre başlar. Masadaki fiziksel lazer modüllerini (Proje 18) doğru aynalara yansıtıp sensörleri tetiklediklerinde, Unreal Engine'deki dijital sandık açılır ve ekranda bir şifre belirir. Bu şifreyi ESP32 Web Server arayüzüne (Proje 23) girdiklerinde oyun motoru DMX sahne ışıklarını (Proje 33) yeşile çevirir.

Bu projede Unreal Engine sadece bir oyun değil, odanın Merkezi Beynidir (Game Master). Unreal, tüm sensörlerden gelen "Bulmaca Çözüldü" (Puzzle Solved) sinyallerini toplayacak, süre bittiğinde veya oyuncular kazandığında gerçek dünyadaki laboratuvar kapısının manyetik kilidini (Maglock) açacak olan ESP32'ye nihai "KAPIYI_AC" komutunu gönderecektir.




🤖 1. Fiziksel Katman: Nihai Kilit (Maglock Kontrolörü)

Atölyenin kapısına veya dev bir sandığa bir Manyetik Kilit (Maglock) bağladığımızı varsayalım. Bu kilidi kontrol etmek için, Proje 24'te öğrendiğimiz "Röle" sistemini kullanacağız. Bu ESP32, sadece Unreal Engine'den gelecek o tek ve kritik UDP komutunu dinler.

// ESP32 KODU: Merkezi Kilit (Kaçış Odası Çıkış Kapısı)
#include <WiFi.h>
#include <WiFiUdp.h>

const char* ssid = "Laboratuvar_WiFi";
const char* password = "Sifre1234";

// Manyetik kilidi veya elektronik grev (strike) kilidi kontrol eden Röle Pini
const int relayPin = 5; 

WiFiUDP udp;
const int dinlemePortu = 8888; 

void setup() {
  Serial.begin(115200);
  pinMode(relayPin, OUTPUT);
  
  // Güvenlik için başlangıçta kilit KAPALI (Röle çekili)
  digitalWrite(relayPin, HIGH); 

  WiFi.begin(ssid, password);
  while (WiFi.status() != WL_CONNECTED) { delay(500); }
  
  udp.begin(dinlemePortu);
  Serial.println("Kilit Modülü Hazır. UE5'ten Komut Bekleniyor...");
}

void loop() {
  int packetSize = udp.parsePacket();
  if (packetSize) {
    char gelenVeri[255];
    int len = udp.read(gelenVeri, 255);
    if (len > 0) gelenVeri[len] = 0; // Metin sonlandırıcı
    
    String komut = String(gelenVeri);
    komut.trim();

    // Unreal Engine'den Zafer Komutu Geldi mi?
    if (komut == "KACIS_BASARILI") {
      Serial.println("OYUN BİTTİ! KAPI AÇILIYOR!");
      
      // Röleyi bırak, manyetik kilidin gücünü kes ve kapıyı aç!
      digitalWrite(relayPin, LOW); 
      
      // 10 Saniye kapıyı açık tut, sonra geri kilitle
      delay(10000);
      digitalWrite(relayPin, HIGH);
    }
  }
}

🟦 2. Blueprint (Unreal Engine) Game Master Mantığı

Unreal Engine tarafında bir "State Machine" (Durum Makinesi) kuruyoruz. Odadaki 3 farklı bulmacadan (Örn: Lazer, RFID ve Şifre) ESP32'ler aracılığıyla ayrı ayrı onay gelmesi gerekmektedir.




Adım Adım Bağlantılar (Mantık Devresi):

  1. Bulmaca Değişkenleri: Level Blueprint içinde 3 adet Boolean (True/False) değişken oluşturun: Bulmaca1_Cozuldu, Bulmaca2_Cozuldu, Bulmaca3_Cozuldu. Başlangıçta hepsi False olmalıdır.
  2. Ağ Dinleyicisi (Dispatcher): Event On UDP Message Received düğümünü Switch on String düğümüne bağlayın.
    • Pinler: PUZZLE_1_OK, PUZZLE_2_OK, PUZZLE_3_OK.
    • Hangi komut gelirse, ona ait Boolean değişkenini Set düğümü ile True yapın.
  3. Büyük Zafer Kontrolü (AND Gate): Her bir bulmaca çözüldüğünde çalışan bir Custom Event (Örn: ZaferKontrolu) tetikleyin.
    • Bu Event çalıştığında, 3 Boolean değişkenini alıp birbiriyle AND (Boolean) düğümleriyle birleştirin. (Yani Bulmaca 1 VE Bulmaca 2 VE Bulmaca 3 True mu?)
    • Sonucu bir Branch'e bağlayın.
  4. Kapıyı Aç (Send UDP): Branch True verirse (Tüm bulmacalar çözüldüyse);
    • Play Sound 2D ile Epik bir zafer müziği çalın.
    • Send DMX ile fiziksel laboratuvardaki tüm ışıkları Zümrüt Yeşiline (Green: 255) çevirin.
    • Ve en önemlisi, ağ eklentinizdeki Send UDP Message düğümünü kullanarak, kapıdaki ESP32'nin IP adresine KACIS_BASARILI komutunu fırlatın! Kapı fiziksel olarak açılacaktır.
