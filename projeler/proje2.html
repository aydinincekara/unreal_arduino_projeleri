Proje 2: Gerçek Dünyaya Dönüş

Sanal Olayların Fiziksel Dünyaya Tepkisi (Unreal -> Arduino)

🎯 Senaryo: Sanal Tetikleyici, Gerçek Işık

Bir önceki projede fiziksel bir butona basıp oyunda bir şeyler ürettik. Bu projede işleri tersine çeviriyoruz! Unreal Engine'deki karakterimiz gizli bir odaya veya güvenli bir bölgeye (Trigger Box) girdiğinde, oyun motoru USB üzerinden Arduino'ya bir sinyal gönderecek. Arduino bu sinyali okuyup masamızdaki fiziksel bir LED'i yakacak. Karakter bölgeden çıktığında ise LED sönecek.


🤖 1. Fiziksel Katman: Arduino Kodu (Dinleyici)

Bu sefer Arduino veri gönderen (Transmitter) değil, veri alan (Receiver) konumunda. Unreal Engine bize "1" gönderirse ışığı yakacağız, "0" gönderirse söndüreceğiz. Bir adet LED'in uzun bacağını (Anot) araya 220 ohm direnç katarak Dijital 8 pinine, kısa bacağını (Katot) GND pinine bağlayın.

// ARDUINO KODU: Gelen Veriyi Dinle
const int ledPin = 8; // LED'i 8 numaralı pine bağladık

void setup() {
  Serial.begin(9600); // Unreal ile aynı iletişim hızı
  pinMode(ledPin, OUTPUT); // LED pinini ÇIKIŞ olarak ayarla
}

void loop() {
  // Eğer USB üzerinden gelen bir veri varsa (Serial.available > 0)
  if (Serial.available() > 0) {
    
    // Gelen tek bir karakteri (harf/rakam) oku
    char gelenVeri = Serial.read(); 
    
    // Unreal bize '1' karakterini gönderdiyse
    if (gelenVeri == '1') {
      digitalWrite(ledPin, HIGH); // Işığı YAK
    }
    // Unreal bize '0' karakterini gönderdiyse
    else if (gelenVeri == '0') {
      digitalWrite(ledPin, LOW);  // Işığı SÖNDÜR
    }
  }
}

🟦 2. Blueprint (Unreal Engine) Kodlaması

Unreal Engine sahnenize sol üstteki ekleme menüsünden Volumes -> Trigger Box (Tetikleyici Kutu) ekleyin ve oyun alanınıza yerleştirip biraz büyütün. Oyuncu bu görünmez kutunun içine girdiğinde Arduino'ya "1", çıktığında "0" yollayacağız.




Adım Adım Bağlantılar:

  1. Olay (Event) Oluşturma: Sahnede seçtiğiniz Trigger Box'a sağ tıklayın. Açılan menüden Add Event -> Collision -> Add On Actor Begin Overlap (İçine girildiğinde) ve ardından aynı menüden Add On Actor End Overlap (İçinden çıkıldığında) düğümlerini Blueprint ekranınıza (Level Blueprint) ekleyin.
  2. Veri Gönderme: OnActorBeginOverlap düğümünden kırmızı bir kablo çekin ve Write String (veya kullandığınız eklentiye göre Print to Serial) düğümünü bağlayın.
    • Port: (Daha önce ArduinoPort değişkenine kaydettiğiniz port bağlantısını Target kısmına bağlayın).
    • String (Gönderilecek Yazı): Kutuya 1 yazın.
  3. Veri Kapatma: Aynı işlemi çıkış için yapalım. OnActorEndOverlap düğümünden kablo çekin ve yine Write String düğümünü bağlayın.
    • String (Gönderilecek Yazı): Kutuya 0 yazın.
✨ Sonuç: Play (Oynat) tuşuna basın. Karakterinizi yürütüp görünmez Trigger Box alanının içine sokun. O an masanızdaki LED'in yandığını göreceksiniz. Kutudan dışarı çıkardığınızda LED anında sönecektir!

🚀 Geliştirme ve Hata Ayıklama

Gecikme (Lag) Varsa: Gelen veri gecikiyorsa, Unreal Engine Blueprint'inizdeki Write komutunun saniyede 60 kere (Tick üzerinden) çalışmadığına, sadece kutuya girildiği an (1 kez) çalıştığına (Overlap Event) emin olun. Aksi halde Serial Port dolar ve kilitlenir.

ARGE Ekibi İçin Meydan Okuma (Challenge):

  • Sadece LED yakmak yerine, bu pini bir Röle Modülüne bağlarsanız, karakteriniz Unreal'da belirli bir odanın şalterini indirdiğinde, sizin bulunduğunuz gerçek odanın lambasını söndürebilirsiniz!
  • Bu mantığı LED yerine bir Titreşim Motoruna (Rumble Motor) bağlarsanız, karakteriniz hasar aldığında (Apply Damage event'i tetiklendiğinde) masanız veya koltuğunuz fiziksel olarak titreyebilir.
