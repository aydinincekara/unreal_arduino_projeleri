Proje 0: Blueprint & Seri Port Kurulumu

Unreal Engine 5 ile Arduino'yu Konuşturmaya Başlıyoruz

🔌 1. Unreal Engine Seri Port Eklentisi (Plugin) Kurulumu

Unreal Engine 5 (UE5), dış dünyadan gelen USB verilerini doğrudan okuyamaz. Bu engeli aşmak için açık kaynaklı ve ücretsiz bir eklentiye ihtiyacımız var (Örn: Serial COM Plugin veya UE4Duino'nun güncel sürümü).

  1. İnternetten UE5 uyumlu bir Serial COM eklentisi indirin.
  2. Unreal projenizin kayıtlı olduğu klasöre gidin (Örn: Belgeler\Unreal Projects\ArduinoTest).
  3. Bu klasörün içine Plugins adında yeni bir klasör oluşturun.
  4. İndirdiğiniz eklenti dosyasını zipten çıkarıp bu Plugins klasörünün içine atın.
  5. Unreal Engine projenizi açın. Üst menüden Edit -> Plugins sekmesine girip eklentiyi bulun ve yanındaki tiki işaretleyip motoru yeniden başlatın.
⚠️ Önemli: Eklentiyi aktifleştirdikten sonra Blueprint pencerinizde sağ tıkladığınızda "Serial" kelimesini aratırsanız, Open Serial Port ve Read Line gibi yeni düğümlerin (nodes) geldiğini göreceksiniz.

🤖 2. Fiziksel Katman: Arduino Kodu

Tıpkı önceki eğitimlerimizde olduğu gibi, Arduino'muzun görevi bir sensörden veri okuyup bunu bilgisayara fırlatmaktır. Basit bir Potansiyometre (A0 pini) bağlayalım ve bu veriyi gönderelim.

void setup() {
  // İletişim hızını 9600 Baud Rate olarak ayarlıyoruz.
  Serial.begin(9600); 
}

void loop() {
  // A0 pinine bağlı potansiyometreden gelen 0-1023 arası değeri oku
  int sensorDeger = analogRead(A0);
  
  // Okunan veriyi Seri Porta yaz ve Alt Satıra in (println)
  // Bu 'ln' (Satır Sonu) kısmı Unreal Engine'in veriyi yakalaması için ZORUNLUDUR!
  Serial.println(sensorDeger); 
  
  // Unreal Engine'i veri yağmuruna boğmamak için kısa bir bekleme
  delay(30); 
}

🟦 3. Blueprint (Görsel Kodlama) Altyapısı

Şimdi Unreal Engine'de bir Actor Blueprint oluşturalım (İsmi BP_ArduinoManager olsun) ve onu sürükleyip sahnemize bırakalım. İçine girip Event Graph (Olay Grafiği) sekmesine geçelim.

Adım Adım Düğüm (Node) Bağlantıları:

1. Portu Açmak (Oyun Başladığında):

Oyuna girdiğimiz an Arduino ile bağlantı kurmalıyız. Event BeginPlay düğümünden kırmızı bir kablo çekin ve Open Serial Port düğümünü bulun.

  • Port: "COM3" (Kendi Arduino portunuzu yazın)
  • Baud Rate: 9600
Bu düğümün Return Value (Mavi çıkış) pinine sağ tıklayıp Promote to Variable deyin ve adına ArduinoPort koyun. (Bağlantıyı hafızaya aldık).

2. Veriyi Sürekli Okumak (Her Karede):

Oyun boyunca Arduino'dan gelen veriyi dinlemeliyiz. Event Tick düğümünden kablo çekin. Ekranın solundaki ArduinoPort değişkenini sahneye sürükleyip (Get) ondan bir mavi kablo çekin ve Read Line düğümünü çağırın. Bu düğüm Arduino'nun println ile gönderdiği metni okur.

3. Veriyi Ekrana Yazdırmak:

Read Line düğümünden çıkan Return Value (Sarı String pini) kablosunu çekip Print String düğümüne bağlayın. Oyunu başlattığınızda sol üst köşede Arduino'dan gelen Potansiyometre sayılarını göreceksiniz!

🛠️ 4. Hata Ayıklama (Troubleshooting)

Erişim Engellendi (Access Denied) Hatası: Unreal Engine'de Play (Oynat) butonuna basmadan önce, Arduino IDE programındaki Seri Port Ekranı'nın (Serial Monitor) kapalı olduğundan kesinlikle emin olun. Portu aynı anda sadece tek bir program kullanabilir!
Veriler Sürekli "0" mı Geliyor?: Arduino kodunuzda Serial.print yerine Serial.println yazdığınızdan emin olun. Unreal Engine'deki "Read Line" komutu, cümlenin sonundaki o enter/satır sonu gizli işaretini görmeden veriyi okumaz.
