Proje 14: Çift Ekran Deneyimi

Unreal Engine Arayüz (UMG) ve Arduino OLED Ekran Senkronizasyonu

🎯 Senaryo: Fiziksel Gösterge Paneli (Dashboard)

Oyunlardaki HUD (Head-Up Display) ekranları oyuncuya can, zırh veya mermi gibi hayati bilgileri verir. Unreal Engine'de bu arayüzler UMG (Unreal Motion Graphics) ile tasarlanır. Bu projede, oyun içindeki mermi sayacımızı (Ammo) Arduino'ya gönderip, gerçek masamızdaki 0.96 inçlik bir OLED ekranda canlı olarak göstereceğiz.

Bu mantık profesyonel yarış simülatörlerindeki fiziksel hız göstergelerinin (Speedometer) ve uçuş simülatörlerindeki altimetrelerin arkasında yatan teknolojinin temelidir.




🤖 1. Fiziksel Katman: 0.96" OLED Ekran (I2C)

OLED ekranımız I2C protokolünü kullandığı için çok az kabloya ihtiyaç duyar. VCC->5V, GND->GND, SDA->A4, SCL->A5 pinlerine bağlanır. Arduino IDE üzerinden Adafruit SSD1306 ve Adafruit GFX kütüphanelerini kurmanız zorunludur.

// ARDUINO KODU: Unreal'dan Gelen Metni OLED'e Yazdırma
#include <Wire.h>
#include <Adafruit_GFX.h>
#include <Adafruit_SSD1306.h>

#define SCREEN_WIDTH 128
#define SCREEN_HEIGHT 64

// I2C adresi genellikle 0x3C'dir.
Adafruit_SSD1306 display(SCREEN_WIDTH, SCREEN_HEIGHT, &Wire, -1);

void setup() {
  Serial.begin(9600);
  
  // Ekranı başlat (Başarısız olursa döngüye gir)
  if(!display.begin(SSD1306_SWITCHCAPVCC, 0x3C)) {
    for(;;);
  }
  
  display.clearDisplay();
  display.setTextColor(WHITE);
  display.setTextSize(2);
  display.setCursor(10, 20);
  display.println("SISTEM");
  display.println("HAZIR");
  display.display();
}

void loop() {
  // Unreal Engine'den yeni bir veri geldi mi?
  if (Serial.available() > 0) {
    
    // readStringUntil('\n') komutu, Unreal'ın gönderdiği satırı sonuna kadar okur.
    String gelenMetin = Serial.readStringUntil('\n');
    
    // Ekranı temizle ve yeni metni yaz
    display.clearDisplay();
    display.setCursor(0, 25); // Yazıyı ortala
    display.print(gelenMetin);
    
    // Ekrana bas!
    display.display();
  }
}
💡 I2C Adresi Hatası: Eğer ekranınız hiç açılmıyorsa I2C adresi muhtemelen farklıdır. 0x3C yerine 0x3D yazarak tekrar test edebilirsiniz.

🟦 2. Blueprint (Unreal Engine) Kodlaması

Oyunumuzda "CurrentAmmo" (Mevcut Mermi) adında bir Integer (Tam sayı) değişkenimiz olsun. Karakter her ateş ettiğinde bu mermi azalacak ve yeni sayı OLED ekrana gönderilecektir.




Adım Adım Bağlantılar (Optimizasyon Şart!):

⚠️ KRİTİK UYARI (Asla Tick Kullanmayın!): I2C ekranlar çok yavaş güncellenir (Yaklaşık 15-20 FPS). Eğer mermi sayısını Event Tick ile saniyede 60 defa Arduino'ya yollarsanız, ekran donar ve Arduino kilitlenir. Veriyi sadece mermi sayısı değiştiğinde göndermeliyiz (Event-Driven Programlama).
  1. Ateş Etme Olayı: Karakterinizin ateş etme tuşuna (InputAction Fire) basıldığında, CurrentAmmo değişkenini 1 azaltın.
  2. Metni Hazırlamak: Yeni mermi sayısını doğrudan yollamak yerine onu güzel bir metin haline getirelim. Boş bir yere sağ tıklayıp Append (Metinleri Birleştir) düğümünü çağırın.
    • A Pinine: MERMI: (Sonuna bir boşluk bırakın) yazın.
    • B Pinine: CurrentAmmo değişkenini sürükleyip bırakın (Otomatik olarak Integer to String dönüşümü yapacaktır).
    • C Pinine (ÖNEMLİ): Add Pin diyerek 3. bir giriş açın. C kutusuna farenizle tıklayıp klavyeden Shift + Enter tuşuna basarak gizli bir "Alt Satıra İnme (\n)" karakteri ekleyin. Arduino'daki readStringUntil('\n') komutunun tetiklenmesi için bu ZORUNLUDUR!
  3. OLED'e Göndermek: Append düğümünün çıkışını alın ve mermi azaldıktan hemen sonra çalışan Write String düğümünün String girişine bağlayın.

🚀 Atölye Tatbikatı: UI Senkronizasyonu

15-30 yaş grubundaki ARGE ekibinizin dikkatini çekecek en güzel projelerden biri budur. Bu sistemi özellikle yarış simülatörü (fiziksel vites ve hız göstergesi) veya FPS oyunlarında (fiziksel şarjör sayacı) kullandıklarında muazzam bir prototipleme becerisi kazanacaklardır.

Geliştirme Görevi (Hata Durumu): Eğer mermi 0'ın altına düşerse veya silah şarjör değiştiriyorsa (Reload), ekrana "RELOADING..." şeklinde yanıp sönen bir uyarı yazdırmak için Arduino kodunda ufak bir if kontrolü yazmalarını isteyin!
