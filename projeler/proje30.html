ESP32-CAM ile Sanal Güvenlik Kameraları ve Gerçek Zamanlı Video Akışı

🎯 Senaryo: Sanal Kontrol Odası (Command Center)

Metaverse ve Digital Twin (Dijital İkiz) projelerinin zirvesinde, fiziksel dünyanın görsel kopyasını sanal dünyaya aktarmak yatar. Sevilen oyun serilerinden "Five Nights at Freddy's (FNAF)" veya askeri drone simülasyonlarındaki kamera mekaniğini fiziksel donanımla gerçeğe dönüştürüyoruz.

Atölyenin bir köşesine yerleştirdiğiniz ESP32-CAM, saniyede 30 kare (30 FPS) video çekecek ve Wi-Fi üzerinden yayınlayacak. Oyuncu, Unreal Engine içindeki güvenlik odasında bulunan 3D monitöre yaklaştığında, gerçek laboratuvarın o anki görüntüsünü sanki oyunun içindeymiş gibi izleyecek!




🤖 1. Fiziksel Katman: Kamera Sunucusu (MJPEG Stream)

ESP32-CAM modüllerinin üzerinde doğrudan bir USB girişi bulunmaz. Kodu yüklemek için bir FTDI (USB to TTL) Programlayıcı kullanmalısınız (U0R->TX, U0T->RX, 5V->5V, GND->GND ve yükleme sırasında GPIO0->GND). Arduino IDE'den hazır gelen CameraWebServer örneğini biraz sadeleştirerek kullanacağız.

// ESP32-CAM KODU: Canlı Video Akışı (Stream) Başlatma
#include "esp_camera.h"
#include <WiFi.h>

const char* ssid = "Laboratuvar_WiFi";
const char* password = "Sifre1234";

// AI Thinker ESP32-CAM Pin Tanımlamaları
#define PWDN_GPIO_NUM     32
#define RESET_GPIO_NUM    -1
#define XCLK_GPIO_NUM      0
#define SIOD_GPIO_NUM     26
#define SIOC_GPIO_NUM     27
#define Y9_GPIO_NUM       35
#define Y8_GPIO_NUM       34
#define Y7_GPIO_NUM       39
#define Y6_GPIO_NUM       36
#define Y5_GPIO_NUM       21
#define Y4_GPIO_NUM       19
#define Y3_GPIO_NUM       18
#define Y2_GPIO_NUM        5
#define VSYNC_GPIO_NUM    25
#define HREF_GPIO_NUM     23
#define PCLK_GPIO_NUM     22

void setup() {
  Serial.begin(115200);

  // Kamera Ayarları
  camera_config_t config;
  config.ledc_channel = LEDC_CHANNEL_0;
  config.ledc_timer = LEDC_TIMER_0;
  config.pin_d0 = Y2_GPIO_NUM; config.pin_d1 = Y3_GPIO_NUM;
  config.pin_d2 = Y4_GPIO_NUM; config.pin_d3 = Y5_GPIO_NUM;
  config.pin_d4 = Y6_GPIO_NUM; config.pin_d5 = Y7_GPIO_NUM;
  config.pin_d6 = Y8_GPIO_NUM; config.pin_d7 = Y9_GPIO_NUM;
  config.pin_xclk = XCLK_GPIO_NUM; config.pin_pclk = PCLK_GPIO_NUM;
  config.pin_vsync = VSYNC_GPIO_NUM; config.pin_href = HREF_GPIO_NUM;
  config.pin_sccb_sda = SIOD_GPIO_NUM; config.pin_sccb_scl = SIOC_GPIO_NUM;
  config.pin_pwdn = PWDN_GPIO_NUM; config.pin_reset = RESET_GPIO_NUM;
  config.xclk_freq_hz = 20000000;
  config.pixel_format = PIXFORMAT_JPEG; 
  config.frame_size = FRAMESIZE_VGA; // VGA Çözünürlük (640x480)
  config.jpeg_quality = 12;
  config.fb_count = 2;

  // Kamerayı Başlat
  esp_err_t err = esp_camera_init(&config);
  if (err != ESP_OK) { Serial.println("Kamera Başarısız!"); return; }

  // Wi-Fi'ye Bağlan
  WiFi.begin(ssid, password);
  while (WiFi.status() != WL_CONNECTED) { delay(500); }
  
  // IP Adresini Yazdır
  Serial.print("Kamera Yayını Başladı! URL: http://");
  Serial.print(WiFi.localIP());
  Serial.println(":81/stream");
}

void loop() {
  // Sunucu arka planda çalışmaya devam eder
  delay(10000);
}
⚠️ URL Yapısı: ESP32-CAM'in standart video akış portu genelde 81'dir. Unreal Engine'de kullanacağımız adres http://192.168.1.55:81/stream formatında olmalıdır.

🟦 2. Unreal Engine Medya Oynatıcı (Media Player)

Bu projede veri almak yerine Unreal Engine'in harika özelliklerinden biri olan Media Framework sistemini kullanacağız.




Adım Adım Bağlantılar:

  1. Medya Altyapısını Kurmak:
    • İçerik çekmecesinde (Content Drawer) sağ tıklayın ve Media -> Media Player oluşturun (Adı: ESP_Camera_Player).
    • Oluştururken çıkan kutucukta "Video output Media Texture asset" seçeneğini işaretleyin. Bu sayede videoyu gösterecek doku (Texture) otomatik oluşur.
  2. Televizyonu / Monitörü Kaplamak:
    • Oluşan Media Texture dosyasına sağ tıklayıp Create Material deyin.
    • Sahnede bulunan bir televizyon veya küp (Static Mesh) modelinin üzerine bu Materyali sürükleyip bırakın. Monitörünüzün ekranı siyah olacaktır.
  3. Yayını Başlatmak (Blueprint):
    • Level Blueprint'i açın. Event BeginPlay düğümünü çağırın.
    • İçerik çekmecesindeki ESP_Camera_Player dosyasını sahneye sürükleyerek referansını alın.
    • O referanstan bir kablo uzatın ve Open URL düğümünü çağırın.
    • URL kutucuğuna Arduino ekranında gördüğünüz adresi (Örn: http://192.168.1.55:81/stream) tam ve eksiksiz olarak yazın!
💡 Electra Player Eklentisi: Unreal Engine 5'te ağ akışlarını (Network Stream) sorunsuz açabilmek için Edit -> Plugins menüsünden Electra Player eklentisini aktif etmeniz performansınızı ciddi oranda artıracaktır.

🚀 Atölye Tatbikatı: İnsansız Kara Aracı (İKA) Entegrasyonu

ARGE ekibiniz için mükemmel bir simülasyon görevi: Proje 8'de yaptığımız fiziksel Joystick ile Chaos Vehicles kontrolü altyapısını hatırlayın.

ESP32-CAM modülünü ve küçük bir güç kaynağını (Powerbank) uzaktan kumandalı (RC) bir arabanın üzerine bantlayın. Gençler laboratuvarın içinde RC arabayı sürerken, arabanın kamerasından gelen görüntüyü Unreal Engine'deki kontrol odası ekranından canlı olarak izlesinler! Bu, endüstriyel insansız kara araçları (İKA) ve drone (İHA) kontrol istasyonlarının birebir aynı mimarisidir.
