Fizikselden Sanala: Donanım Entegrasyonu

Arduino ve Unreal Engine 5 ile Gerçek Zamanlı Veri Haberleşmesi
Seviye 1: İlk Temas (Başlangıç)

Hedef: Portu Açmak ve İlk "Merhaba"yı Duymak

Amacımız Unreal Engine ile Arduino arasındaki seri haberleşme (Serial Communication) otoyolunu inşa etmek ve kapıları açmaktır.

1. Arduino Görevi (Donanım)

Arduino'nun sürekli olarak bir sinyal göndermesini sağlıyoruz.

void setup() {
  Serial.begin(9600); // İletişim hızı (Baud Rate)
}
void loop() {
  Serial.println("Baglanti Basarili!"); // Veriyi gönder ve alt satıra geç
  delay(500); 
}

2. Unreal Engine Görevi (Yazılım)

1
Kapıyı Aç (BeginPlay): Open Serial Port düğümünü ekleyin. Aygıt Yöneticisindeki Arduino COM port numaranızı (Örn: 3) yazın. Hızı 9600 yapın.
2
Kanalı Kaydet: Mavi Return Value çıkışına sağ tıklayıp Promote to Variable deyin. Adını "MySerial" yapın.
3
Veriyi Oku (Tick): Serial Read Line düğümünü ekleyin, MySerial'ı Target'a bağlayın. Çıkan sonucu Print String ile ekrana yazdırın.
Kritik Hata Önlemi (Error: 00000006): Oyunu kapattığınızda portun açık kalıp kilitlenmemesi için Event EndPlay düğümüne Close Serial Port bağlamayı ASLA unutmayın!
Kontrol Noktası: Play tuşuna bastığınızda sol üstte "Baglanti Basarili!" yazısı akıyorsa 2. Seviyeye geçmeye hazırsınız.
Seviye 2: Veri Ayrıştırma (Orta Düzey)

Hedef: Çoklu Sensör Verisini Paketlemek ve Çözmek

Sensörlerden (Joystick X, Y ve Buton) gelen verileri tek satırda gönderip, Unreal içinde doğru çekmecelere ayırmayı öğreneceğiz. Bu yönteme CSV (Virgülle Ayrılmış Değerler) denir.

1. Arduino Görevi (Paketleme)

void loop() {
  int xVal = analogRead(A0);
  int yVal = analogRead(A1);
  int swVal = digitalRead(2);

  // Verileri arasına virgül koyarak tek satır yapıyoruz
  Serial.print(xVal);
  Serial.print(",");
  Serial.print(yVal);
  Serial.print(",");
  Serial.println(swVal); // SADECE en sondakinde println kullanılır!
  delay(50);
}

2. Unreal Engine Görevi (Çözümleme)

1
Temizlik (Trim): Serial Read Line'dan çıkan kabloyu Trim düğümüne bağlayın. Görünmez satır sonu boşluklarını temizleriz.
2
Torbaya Ayır (Parse Into Array): Trim'den çıkan veriyi bu düğüme bağlayın. Delimiter kutusuna SADECE virgül , yazın.
3
Veriyi Çek (Get): Parse düğümünün sarı çıkışından Get (a copy) düğümleri oluşturun. Index 0 X'i, Index 1 Y'yi, Index 2 Butonu verir.
Pedagojik İpucu (Renklerin Dili): Unreal'da Pembe kablolar Metin (String), Sarı kablolar ise Dizi (Array/Torba) anlamına gelir. Parse düğümü pembeyi alır, içindeki virgülleri koparıp size sarı bir torba verir.
Seviye 3: Oyuna Hükmetmek (İleri Düzey)

Hedef: Verileri Değişkenlere Kaydedip Oyun Mantığına Bağlamak

Ekranda akan yazılar sadece bilgi verir. Karakterleri yürütmek veya ışıkları açmak için bu metinleri matematiksel değerlere dönüştürüp kalıcı hafızaya almalıyız.

1. Unreal Engine Görevi (Tür Dönüşümü ve Kayıt)

1
Kutu Oluşturma (Variables): Sol panelden Joystick_X adında yeni bir değişken oluşturun. Türünü Integer (Turkuaz renk) olarak ayarlayın.
2
Matematiğe Çevir (To Integer): Get (0) düğümünden çıkan pembe kabloyu To Integer düğümüne bağlayın. Metni sayıya çevirdik!
3
Kutuya Koy (Set): `Joystick_X` değişkenini sahneye bırakıp Set seçin. To Integer'dan çıkan yeşil kabloyu Set düğümüne takın. Akış için beyaz kabloyu bağlamayı unutmayın.

Ne Başardık?

Artık Unreal Engine'in herhangi bir yerinden (Karakter Blueprinti, UI, Level Blueprint) Get Joystick_X diyerek donanımdaki fiziksel hareketi anında oyun mekaniğine yansıtabilirsiniz. Örneğin bu sayıyı `Add Movement Input` düğümüne bağlayarak karakterinizi fiziksel joystick ile yürütmeye başlayabilirsiniz!

Profesyonel Raporlama: Verileri test ederken Print String ile Format Text düğümünü kullanın. İçine X={A}, Y={B} yazarsanız değişkenleri çok daha estetik izleyebilirsiniz.
